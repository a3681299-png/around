# 円形マスクとシグナルの最小プロトタイプ

`codex/creator-editor-spike` のA＋D＋G実験。素材を照明で加工する機能ではなく、入力をレイヤーの表示へ接続する小さな制作機能を作る。

## 触り方

1. 実験worktreeの `dist` を専用Chromeプロファイルへ読み込み、YouTubeでテーマをONにする。
2. 「デザインを編集（実験）」から画像を追加し、位置・サイズを決める。大きな背景イラストを使うと、光の下だけに別世界が見える。
3. 画像を選び、プロパティの「マスクと振る舞い」で「円形マスクを使う」をONにする。
4. 半径、境界のぼかし、表示強度を調整する。「マウスに追従」は初期ON。外すとレイヤー中央を照らす。
5. 動画ページで「動画の一時停止で隠す」をONにする。再生中は設定強度、一時停止・終了・プレイヤー不在では0%へフェードする。時間は0〜5000ms。
6. 保存すると他タブと再読み込みへ反映する。未保存の設定は破棄でき、追加・設定変更・移動は既存のUndo／Redoで戻せる。

プロパティパネル上では直前のキャンバス位置を保つため、数値を編集しながら光の見え方を確認できる。最初のマウス移動前は中央を照らす。選択枠・ハンドルにはマスクをかけず、見えていない部分からも画像を動かせる。通常モードはクリック透過。

PNG／WebPを最初の用途とし、同じレイヤー属性と合成段階をGIF・アニメーションWebP・Lottieにも適用できる。これはレイヤーの表示を隠すマスクであり、YouTubeの映像の画素や明るさは読まない。

## 入力と接続

| 分類 | ソース | 意味 |
| --- | --- | --- |
| 値 | `pointer.position` | 最新の画面内マウス座標。新しいサンプルで置き換える |
| 状態 | `video.playing` | メインプレイヤーの `!paused && !ended`。不在はfalse |
| 出来事 | `video.play` / `video.pause` / `video.ended` | ネイティブイベントが発生した1回の通知 |

状態と出来事を混同しない。今回の保存可能な接続は値と状態の2種類だけ。出来事はAdapterの通知とカタログに定義し、イベントからの条件分岐やタイムラインは後の拡張に残す。

| ソース → 変換 → ターゲット | 動作 |
| --- | --- |
| `pointer.position` → `layer-local` → `mask.center` | 現在のアンカー矩形と画像の回転を逆変換し、レイヤー内のpx座標を求める |
| `video.playing` → `boolean-gate` → `mask.intensity` | true=1／false=0の係数へ変換し、設定時間でフェードする |

入力を直接位置へ書き込まない。画像の不透明度、マスクの表示強度、シグナルの係数を掛け合わせて描画する。再生・停止を途中で切り替えた場合は現在値からフェードを反転し、マウス移動ではフェードを再開しない。

## 保存データ

DesignDocument v5の各レイヤーに、任意の `effects` を追加する。現在は円形マスクを各レイヤー1つまで受け付ける。無効にしても設定は保持する。

```json
{
  "effects": [{
    "kind": "mask",
    "shape": "circle",
    "enabled": true,
    "center": { "x": 0.5, "y": 0.5 },
    "radiusPx": 160,
    "featherPx": 40,
    "intensity": 1,
    "bindings": [
      {
        "source": "pointer.position",
        "transform": { "kind": "layer-local" },
        "target": "mask.center"
      },
      {
        "source": "video.playing",
        "transform": { "kind": "boolean-gate", "fadeMs": 350 },
        "target": "mask.intensity"
      }
    ]
  }]
}
```

既存の `placement.anchor` とasset IDをそのまま利用する。旧v1〜v4は読み込み時にv5へ移行し、エフェクトを勝手に追加しない。明示的に保存するまで元のストレージ値は書き換えない。素材のIndexedDB形式と権限は変えない。

登録済みソース・変換・ターゲットの組み合わせだけを検証して受け付ける。同じターゲットへの重複接続、未知のフィールド、式、URL、CSS、スクリプト、範囲外・非有限の数値は拒否する。半径は1〜4096px、ぼかしは0〜4096px、強度は0〜1。ぼかしは円の内側に設け、半径より大きい場合は中心からのグラデーションにする。

## 責務

| モジュール | 責務 |
| --- | --- |
| `sites/youtube-signals.ts` | メイン動画の発見・交換、ネイティブ状態と出来事の通知。hover previewを除外 |
| `signals/types.ts` / `sources.ts` | 入力の分類、最新サンプル、必要なソースの共有・接続・解除 |
| `effects/types.ts` / `schema.ts` | 素材形式に依存しないエフェクトと宣言的接続、保存入力の検証 |
| `effects/evaluate.ts` | ソースの変換、座標計算、連続したフェード、マスクの計算 |
| `effects/controller.ts` | 合成と実行時状態、必要なフレーム予約、媒体への表示状態通知 |
| `design/image-renderer.ts` | 既存のアンカー追従・選択枠・ジェスチャーと、共通の合成段階を接続 |
| `media/controller.ts` | 素材の復号・再生。マスクの強度が0になったアニメーションの時計を止める |
| `editor/effects-panel.ts` | 設定フォーム。draft・履歴・保存は既存のcontrollerへ委譲 |

マスクはメディアのコンテナへ適用し、選択枠から分離する。将来の別素材もLayerStateと合成段階を共有できる。UIレイヤーや3Dでは描画先に合う合成実装を別途追加する必要があり、今回それらの表示対応を実装したわけではない。接続構造はフォームに依存せず、将来別の編集UIからも作れる。

## 実行と停止

- マウスイベントは必要な表示レイヤーがあるときだけ共有する。1タブに1リスナー。入力は受けても、全てフェードアウト済みならマウス移動による描画を予約しない。
- ネイティブ動画は1つだけ購読し、既存Adapterのページ更新で接続先を再確認する。プレイヤーの入れ替えで旧リスナーを解除する。
- マウスの更新は1描画フレームへまとめる。フェードは終了後に予約を止め、静止中のポーリングはしない。
- 画面外・非表示・不透明度0・強度0のレイヤーにはシグナル接続を維持しない。スクロール・サイズ変更・SPAで再び有効になれば最新の状態から再開する。
- 非表示タブではシグナル購読とフレーム予約を解除し、復帰時に再取得する。`prefers-reduced-motion`ではフェードを即時切替にする。手動のマウス追従は維持する。
- テーマOFF／全体の強さ0%では、既存のdestroy経路でDOM、マスク、シグナル購読、フレーム予約、再生処理を撤去する。

CSSの生成グラデーションによるalphaマスクを使う。参照: [MDN mask-image](https://developer.mozilla.org/en-US/docs/Web/CSS/mask-image)、[HTMLMediaElement playing](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/playing_event)、[visibilitychange](https://developer.mozilla.org/en-US/docs/Web/API/Document/visibilitychange_event)。外部スクリプト・外部素材取得・新しいChrome権限・依存パッケージは追加しない。

## 検証範囲

自動テストは本物のMV3拡張・Chrome Storage・IndexedDBとローカルYouTube fixtureを使用する。ネイティブ動画はローカルCanvas stream。スクリーンショットの画素で円の内外とぼかしを確認し、保存・再起動・Undo／Redo・破棄・タブ同期・回転・リサイズ・スクロール・SPA・OFFを検証する。

実YouTubeでの最新DOM、広告・ミニプレイヤー・シアター・全画面切替・ライブ配信・実動画の負荷は未検証。32枚の小さなfixtureの数値を、大きなイラスト32枚や実サイトのGPU負荷の保証に使わない。今回の対象にノードエディター、WebGLライティング、画素解析、本格タイムライン、UI素材や3D描画は含めない。
