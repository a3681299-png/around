# Playground 3D とデスクトップの取り込みレビュー（2026-11-08）

対象：`codex/playground-3d` の `0f0f3b4`、`codex/playground-desktop` の `75d6eeb`。作業ブランチ（v17）の `6a1badc`・`18de676` で取り込んだ。Playground は Codex の持ち場なので、中身は直さず、取り込みと型・テストを通すところまでにした。

**判定：取り込んでよい（残りあり）。** 4つの線（G1・読める・作品データの安全・権利）に触れるものはなかった。

## 取り込みで合わせたこと

| 所                                                | 合わせ方                                                                                                                                                                                           | 理由                                                                                                             |
| ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 素材の読み込み（`scripts/playground/content.ts`） | 作業ブランチの「許可した素材をハッシュで照合する」読み込み（`mirdo-assets.json`）を残し、3D の板とデスクトップの部屋が使う座り・立ち・座り始め・歩き・跳ねの動作を、その中から名前で選ぶようにした | 2つのブランチが別々に私用の素材を読んでいた。3D 側の読み込みはパスの外れだけを見て、中身を照合していなかった     |
| 素材の場所の変数                                  | `AROUND_PLAYGROUND_MIRDO_ROOT` と `AROUND_PLAYGROUND_PRIVATE_ASSETS` のどちらでも同じ checkout を指せるようにした                                                                                  | 手順書が2つの名前に分かれていたため                                                                              |
| 最初の状態                                        | 適用前の素のサイトから始める（`#desktop` で直接開いたときだけ適用済み）                                                                                                                            | デモの台本の場面1→2。ミルドの取り込み（`e99d2cf`）は、ミルドのビルドで適用済みから始めていた                     |
| 足の余白（`style.css`）                           | 操作帯の上の 48px の余白を、板が開いていない基本版で適用したときだけに絞った（`data-around-basic`）                                                                                                | 余白でページが窓より高くなり、3D の板が開く条件（`spatial.ts`）から外れていた。3D の板では、ミルドは板の縁に座る |
| ミルドの基本版のテスト                            | 板が開かない幅（940px）で開き、適用を押してから確かめる                                                                                                                                            | 本物の GPU がある headless では板が開き、基本版のミルドが出ないため                                              |
| クレジット                                        | ミルドと Quaternius のクレジットを、3D 版の足元に残した                                                                                                                                            | 規約の表示                                                                                                       |

## 気づき（こうすると良くなる）

- 3D の板の座る位置（下の縁の左寄り）が、足元のクレジットの行と重なる。座る所をクレジットの左か、板の上の縁にすると、文字に足が掛からない
- デスクトップの部屋のレイアウト（`desktop-layout.json`）と、拡張の「奥の部屋」の配置データ（`src/world` 側に足す予定）は、同じ部屋を2通りに書くことになる。本番の部屋（11/15〜）では、同じ配置データを両方から読むと、翔太の手間が1回で済む
- 前回の指摘（開いたときの T ポーズ、上の縁に座らず下へ戻る、足が音量のつまみに乗る）は、3D の板では起きていない。基本版の T ポーズは `93a0bbd`（姿勢が来るまで描かない）で直っている。基本版の足は上の余白の絞り込みで今までどおり
- ノート PC の内蔵 GPU での 100/125/150% の重さと傾いた板のクリックは、今回は測っていない（取り込みと型・テストまで）。塊の終わりの Codex の検証で見てほしい
