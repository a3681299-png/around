# サイドパネルの操作整理

## 変更範囲

- サイドパネルの表示状態を認証済みPortでページへ通知する。表示中はページ側の小型ツールバーを隠す。Chromeの×で閉じたときや接続が切れたときは戻す。編集セッション、選択、直接操作ハンドルは維持する。
- パネル幅720px以上ではプロパティとレイヤーを左右に配置する。それ未満では上下に戻す。区切りの方向も追従し、縦横の分割比を別々に保存する。数値欄は最大104px、名前や基準も上限を設ける。
- サイドパネルの内側の×を除き、終了は「ファイル → 編集を終了」にまとめる。インページへの切替は分割画面、独立Studioはウィンドウのアイコンにする。名称はツールチップとアクセシブル名に残す。
- 単一オブジェクトが選ばれていない間は、不透明度のつまみを隠し、トラックを薄くする。ロック中の選択では現在値を表示する。
- 履歴・保存、素材追加、操作ツールの間に細い区切りを入れる。

作品データ、World Runtime、Editor Core、権限は変更しない。表示通知は編集コマンドや履歴として扱わない。

## 検証

Chromeの実サイドパネルで、表示・非表示とページツールバー、直接移動、履歴、保存、表示面の切替を検証する。パネルWebContentsの幅を変えたレスポンシブ検査は、Chromeの区切りを手でドラッグした検査とは区別する。インページ・独立Studioの既存回帰も実行する。

## 検証結果（2026-10-18）

- 型チェック（アプリ・World Runtime・Editor Core）、lint、実験版ビルド: 成功。
- 関連自動テスト34件: 全件成功、1.2分。Core、クイック編集、インページ、独立Studio、公式パネルを検証。今回、全自動テスト一式の再実行は行っていない。
- 公式パネルの新規回帰: 360pxで上下、940pxで左右、数値欄104px以内、未選択トラックのつまみ除去、ロック時の値表示、異なる切替アイコンとツールチップ、ツールバーの区切りを確認。閉じる・開き直す・直接移動・Undo/Redo・保存・再読み込み後も編集を維持した。
- 幅変更で旧タブUIのメディアクエリ処理がプロパティを隠す競合を検出し、Workbenchの同時表示を優先するよう修正した。
- 実YouTubeの別テスト1件: 成功、28.9秒。1366px・1920px・1000pxのChrome外枠幅で、ページ側の重複ツールバーがなく、再生・設定・シアター・全画面のボタンへクリックが届く。グループマスク、動画一時停止のフェード、スクロール追従、保存・再読み込み、SPA、強さ0%の撤去も確認。
- Chromeの区切りを手でドラッグする幅変更は未検証。360px/940pxのUI検査はパネルWebContentsの表示幅を変更したもので、実YouTubeの検査ではChromeのウィンドウ幅を変更した。
- mainは変更なし。通常版distの12ファイルは作業前後のSHA-256が一致。権限と作品データ形式の変更なし。
