# Signal Timeline v1

## 起点と責務

起点は実験ブランチ `9c9cd88`。現在のHost入力、純粋なWorld Runtime、DOM Renderer、Editor Core、共通Workbenchを拡張する。mainと通常版distは変更しない。Chrome権限と依存パッケージは追加しない。

- **作品ルール**: DesignDocument v8の `signalRules[]`。対象レイヤー・プロパティ、駆動元、座標系、入力範囲、キーフレーム、補間、評価・平滑化・合成方針を持つ。v1はページYスクロール進捗、opacity、往復追従、平滑化なし、置換。時間を特別扱いせず、ソースの追加で拡張する。v1では同じプロパティへの複数の有効ルールを拒否し、未対応の合成を推測しない。
- **Runtime**: 生のscroll位置とスクロール可能範囲から進捗を計算する。入力時刻に関係なく同じ位置を同じカーブで評価する。UI、DOM、時計、乱数へ依存しない。グループと子のopacityは既存の階層で合成し、マスクも維持する。
- **Editor Core**: ルール変更を既存の編集コマンドと履歴へ接続。ドラッグはbegin/endで1操作。レイヤーの削除・複製・グループ解除でルール参照を整合させる。ロックを尊重する。
- **Studio UI**: 同じWorkbenchへ折りたたみ式のSignal Timelineを追加。パネル内に置き、YouTubeへ領域を追加しない。シグナル空間の横軸は進捗%、縦軸は不透明度%。テイク表示の横軸は記録時間。両方にズーム・横スクロール・再生ヘッドを用意する。
- **Hostとテイク**: 明示的な録画だけを許可。既存World入力検証・記録を再利用し、最大20Hz、件数・期間・容量予算で停止。時刻、順序付きイベント、マウス・生scroll・範囲、viewport、意味的アンカーだけを保持する。ページ本文、URL、文字入力は記録しない。テイクは作品と別のIndexedDBへ保存し、素材を複製しない。
- **入力切替**: live / recording / playback / pausedを明示。再生・シーク時は記録入力だけをRuntimeへ渡す。実サイトへ操作を再送しない。シークと逆方向は初期状態から必要な入力を再評価し、状態を復元する。終了・OFFで購読と再生処理を止め、ライブへ戻す。
- **投影**: テイク中に各キーの進捗値を通過した時刻を求める。往復では複数のゴーストを表示する。ゴーストは派生表示で、作品にもテイクにもキーとして保存しない。

## 段階

1. **ルールエンジン**: 厳格なv8移行・検証、純粋な補間、raw scroll入力、DOM反映、速度非依存・既存機能の回帰。
2. **キーフレームエディター**: カーブとキーの直接編集・数値入力・線形/イージング、Core履歴、保存・破棄、Studio共通UI。
3. **録画・再生**: 制作用Hostセッション、テイクの独立保存、通信、波形、入力隔離、再生・停止・シーク。
4. **投影と仕上げ**: 時間/シグナル表示切替、ゴースト、スクリーンショット、決定性・負荷測定、実YouTubeの一連操作。

各段階で型チェック・lint・ビルド・既存全自動テストを実行し、成功を確認してコミットする。実サイト検証はfixtureと分けて記録する。未対応のモードや素材形式の追加、タイムライン上の映像編集、式・任意スクリプトの実行は行わない。

## 互換性

v1〜v7は純粋なparseDesignでv8へ再構築する。ルールなしの見た目を維持する。Runtimeは1.1へ更新し、旧開発用記録はルールのない入力として読み込む。新テイクは別形式で、作品の配布に同梱を要求しない。既存アセットDBは変更せず、テイク専用DBを用意して素材のlease・Undo中の保持と干渉させない。

## 段階ごとの検証

- Stage 1: 型チェック・lint・ビルド成功。全264件の最終実行は256成功／8件opt-inスキップ、2 workers、5.5分。初回全体回帰でv8を拒否する旧期待値と未購読時の解除を検出し、修正後に全件を再実行した。速度・往復・ゼロ範囲・グループとマスク・基底opacity 0からの復帰・ルール参照・旧データを検証。実YouTube検証はUI完成後に別途行う。
- Stage 2: 型チェック・lint・ビルド成功。全267件は259成功／8件opt-inスキップ、2 workers、5.7分。公式パネル、インページ、独立Studioで同じコマンドによるキー編集を確認。ドラッグ1操作のUndo、キーだけのDelete、ロック、保存・破棄・再読み込み、ズーム・高さ調整を検証。接続中の不透明度は手動値と区別して表示する。
