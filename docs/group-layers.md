# グループレイヤー

`codex/creator-editor-spike` の実験機能。複数の素材を一つの合成対象として扱い、共通の不透明度やマスクを設定する。最初の実装は1階層。

## 最初の制作体験

1. 実験worktreeの `dist` をChromeへ読み込み、テーマをONにして「デザインを編集（実験）」を開く。
2. 画像を3枚追加し、位置とサイズを決める。
3. 一覧でCtrl／Shiftを使って3枚を選び、「選択をグループ化」を押す。
4. グループの名前を付け、枠の縁または子の画像をドラッグして全体を移動する。矢印キーとShift＋矢印も使える。
5. グループの「マスクと振る舞い」で円形マスクをONにし、半径・ぼかし・表示強度を調整する。マウスを動かすと、その範囲だけ素材が見える。
6. 動画ページで「動画の一時停止で隠す」をONにし、フェード時間を決める。
7. 保存する。再読み込みや同じChromeプロファイルでの再起動後も、配置・親子関係・振る舞いを復元する。
8. 不透明度100%のグループを選び「グループを解除」を押す。各画像の位置と個別エフェクトは保ち、グループのマスクを外す。

グループを選択しているときは、子の画像をドラッグしても全体が動く。個別に編集する場合は、一覧の子を選ぶか、キャンバスでCtrl／Shiftクリックする。子の拡縮・回転・名前・不透明度・個別マスクを引き続き編集できる。

一覧の▾／▸で折りたたみ・展開する。折りたたみは一覧表示だけを変え、作品を非表示にしない。キャンバスから子を選択すると、その親を展開して選択行を表示する。折りたたみ状態はタブ内のUI状態として扱い、作品JSONやUndo履歴には含めない。

## グループの操作

| 操作         | 動作                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| 移動         | 子へ共通の画面上の移動量を適用。非表示の子も含め、基準内で全体を一緒に止める |
| 表示・非表示 | 子自身の表示設定を保持したまま、親で全体を隠す                               |
| ロック       | 親がロック中なら子の移動・変形・削除なども止める                             |
| 子のロック   | その子の個別編集を止め、グループ全体の移動・削除・複製も止める               |
| 不透明度     | 子を合成した結果へ1回適用。重なった部分を二重に薄くしない                    |
| 重なり順     | グループを最上位の1レイヤーとして扱う。子同士の順番は内部で管理する          |
| 複製         | 親子に新しいレイヤーIDを付ける。asset IDは共有し、画像データを再保存しない   |
| 削除・履歴   | 親子を1操作として削除・復元。保存後のUndoでも必要な素材を保持する            |

グループ化、解除、ドラッグ、キー移動、並び替え、設定変更は既存のdraftと履歴へ記録する。ドラッグ中の更新は開始から終了まで1操作。保存・破棄・終了時の扱いは他のレイヤーと共通。

## 配置と保存

DesignDocument v6に任意の `groups` を追加する。メディアは従来どおり `decorations` に置き、グループは既存レイヤーのIDを参照する。

```json
{
  "groups": [
    {
      "kind": "group",
      "id": "group-world",
      "name": "海の世界",
      "children": ["image-one", "image-two", "image-three"],
      "opacity": 1,
      "zIndex": 0,
      "visible": true,
      "locked": false
    }
  ]
}
```

これは文書に追加する部分の例。グループにも共通の `effects` を設定でき、形式は [effects-and-signals.md](effects-and-signals.md) と同じ。グループは素材を持たないため、画像・GIF・アニメーションWebP・Lottieを同じ仕組みで参照できる。3Dモデルの描画自体は未実装。

子の `placement` は変更せず、元の画面／プレイヤー基準の座標を保つ。グループの矩形は、回転を含む全ての子の矩形から毎回求める。非表示の子も矩形に含めるため、表示の切替だけでマスクの基準枠を変えない。

グループ化・解除時に子を別の座標系へ変換しない。解除後も座標は同じ値のまま。画面サイズ変更時には従来の各レイヤーと同じ割合の配置として追従する。Figmaのような親のローカル座標や、内部間隔をCSS pxで固定したグループ変形はまだ実装しない。

旧v1〜v5は読み込み時にv6へ移行し、グループを勝手に追加しない。空の `groups` は省略し、明示的に保存するまでストレージの元データを上書きしない。画像とasset ID、個別エフェクトを維持する。IndexedDBの形式と権限は変更しない。

循環・多重所属・不明なID・親子のID衝突・空グループ・未知のフィールドは拒否する。子は既存メディアだけに限定し、グループを子にするネストは拒否する。素材は全体32レイヤー、アニメーションは8、グループは16まで。

## 合成と停止

グループ内の画像をDOM上の同じコンテナへ移し、そのコンテナへマスクと不透明度を適用する。画像のDOM・メディアインスタンスは保持する。グループ化や並び替えだけでデコーダーを作り直さない。

個別エフェクトは各メディアに、グループのエフェクトは合成結果に適用する。共有の `EffectController` へ親を先、子を後に渡し、`parentId` で表示状態を伝える。親の強度が0なら子のアニメーションも停止し、子のマスクのための不要なシグナル購読を止める。グループ専用のシグナルや再生時計は作らない。

固定マスクの中心は現在のグループ矩形を基準とする。子を動かすと矩形は変わるが、半径・ぼかし・強度・接続設定を保つ。マウス追従では、矩形が変わっても画面上のマウス位置を中心に維持する。

選択枠は合成コンテナの外側に置き、マスクや不透明度の影響を受けない。通常モードでは枠と操作領域を隠し、装飾はクリック透過。OFF／強さ0%ではDOM・マスク・シグナル・再生処理を既存のdestroy経路で撤去する。非表示タブと動きを減らす設定も既存の停止処理を共有する。

グループ全体への不透明度やマスクは、子へ同じ数値を配る方法と、画像が重なる部分の結果が異なる。合成の根拠は [W3C Compositing and Blending](https://www.w3.org/TR/compositing-1/#groupinvariance)、[CSS Masking](https://www.w3.org/TR/css-masking-1/) を参照。

## 責務

| モジュール                          | 担当                                                       |
| ----------------------------------- | ---------------------------------------------------------- |
| `design/types.ts` / `schema.ts`     | 共通の外観、グループ参照、v6移行と入力検証                 |
| `design/hierarchy.ts` / `frames.ts` | 親子、兄弟順、選択の正規化、グループ矩形と移動対象         |
| `editor/groups.ts`                  | グループ化・解除・階層内の順序・複製・削除。純粋な文書操作 |
| `editor/controller.ts`              | draft・履歴・保存・素材保持へ操作を接続                    |
| `editor/layer-tree.ts`              | 階層一覧・折りたたみ・選択表示・ドラッグ入力               |
| `design/image-renderer.ts`          | 合成コンテナ、子の描画位置、選択枠と共通のジェスチャー     |
| `effects/controller.ts`             | 親子共通のマスクとシグナル、表示状態の伝播                 |

画像データ・メディア時計・ネイティブ動画の検出は、それぞれ既存のassets／media／SiteAdapterへ残す。

## 初期版の制約

- 同じ配置基準の最上位素材を2枚以上選んでグループ化する。画面基準とプレイヤー基準の混在、グループ内でのアンカー変更、グループのネストは拒否する。
- 最上位の重なり順で連続する素材だけをグループ化する。間の別レイヤーをまたぐと見た目を保持できないため、先に作者が並び替える必要がある。
- 並び替えは同じ階層の兄弟同士だけ。ドラッグによる親の変更は未対応。
- グループの拡縮・回転、グループを含む整列・等間隔配置は未対応。移動・矢印キー・スナップは使える。
- 解除は親の不透明度100%で行う。半透明の合成を子へ配ると重なり部分の見た目が変わるため、初期版ではその解除を止める。
- 解除するとグループのエフェクトを外す。個別エフェクトは残す。非表示のグループを解除した場合は子も非表示にして、突然表示しないようにする。
- 矩形・自由形状マスク、複雑な合成、タイムライン、グループのローカル変形は次段階。

## 検証範囲

自動テストは本物のMV3拡張機能、Chrome Storage、IndexedDBを使うが、YouTubeのページと動画はローカルfixtureへ差し替える。3枚の制作フロー、合成した画素、ブラウザー再起動、保存済み削除のUndo、階層のドラッグ並び替え、複数タブ同期、プレイヤーのサイズ変更・スクロール・SPA、GIF／Lottieの停止と復帰を検証する。

16グループ・32素材にロック・非表示・不透明度0・個別マスクを混在させ、入力の共有、静止時と非表示時の停止、OFF／0%の解除も確認する。実YouTubeの最新DOM、広告・ミニプレイヤー・全画面、実素材を含むCPU／GPU負荷は未検証。測定値は大きな作品の性能保証には使わない。
