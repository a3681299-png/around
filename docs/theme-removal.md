計画：`docs/theme-removal-plan.md`。撤去前の最後のコミットにタグ `retro-theme-final`（`6ce22ce`）を付けた。レトロテーマのコードとピクセル書体は、このタグから取り出せる。

| 項目                           | 決定                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| タグ                           | `retro-theme-final` を `6ce22ce` に付けて push                                                                |
| ON/OFF                         | 名前は「作品を表示する」。既定値は ON に変える。強さ 0% で OFF にしていた人は、撤去の更新で1回だけ OFF へ移す |

テストと計測の前に、作ったビルドで撮って目で確かめた。作品は、撤去前に作った形（`baseThemeId: 'retro'`、動画カードと検索欄の着せ替え）。

### 計測（本物の YouTube、交互に6組）

`scripts/ui0c/marks.mjs`（`UI0C_MODE=ui0d3`・`UI0C_FEATURES=off`）、撤去前（`retro-theme-final`、表示オプションは全部 OFF、テーマなしの作品）と2回目のビルド。4組を測ったあと、起動直後の1組の p95 が +1.2ms だったので、2組を足して6組にした（スキル `wwt-perf`：起動直後は組ごとのばらつきが大きい）。生データは `docs/benchmarks/theme-removal-2.json`（組1〜4）と `theme-removal-2b.json`（組5・6）。

| 定常       | すべて 0          | すべて 0                           | 0                | 合格 |

単位は ms（拡張の CPU 時間、1フレームあたり）。起動直後の p95 は、撤去前が 0.9〜2.4、撤去後が 1.3〜2.4 で、まとめると中央値は 1.75 → 1.95（+0.2）。計測は `baseThemeId: null` の作品（テーマの CSS も表示オプションも外れる状態）なので、撤去で減ったのは作品によらず動いていた部分（ピクセル書体の読み込み・テーマの CSS の文字列の用意など）だけで、差は揺れの範囲に収まった。レトロテーマを ON にして使っていた人にとっては、窓の飾りの時計（毎秒）や掲示板の番号付けがなくなるので、それより軽くなる（測っていない）。
