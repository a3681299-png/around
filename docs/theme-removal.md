# レトロテーマの撤去

計画：`docs/theme-removal-plan.md`。撤去前の最後のコミットにタグ `retro-theme-final`（`6ce22ce`）を付けた。レトロテーマのコードとピクセル書体は、このタグから取り出せる。

## 決めたこと（翔太、2026-11-01）

| 項目                           | 決定                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| タグ                           | `retro-theme-final` を `6ce22ce` に付けて push                                                                |
| ON/OFF                         | 名前は「作品を表示する」。既定値は ON に変える。強さ 0% で OFF にしていた人は、撤去の更新で1回だけ OFF へ移す |
| 新しい作品の `baseThemeId`     | `null` で作る。既存の作品は書き換えない                                                                       |
| 読まなくなった 15 個の保存キー | 残す                                                                                                          |
| 画面の名前                     | 「設定」                                                                                                      |
| `chrome-safety.spec.ts`        | 消してよい                                                                                                    |
| ピクセル書体                   | 素材とライセンスごと消してよい                                                                                |

## 0回目：タグ

`retro-theme-final` → `6ce22ce`（注釈付きのタグ）。push 済み。

## 1回目：撤去の前にテストで押さえる

製品の挙動は変えていない。

### 変えたこと

| 変更                                                                                                      | 理由                                                                                                                                                                                                                                                                                                          |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ON の印を `data-ww-theme="retro"` から `data-ww-site="youtube"` へ（テスト 16 本と helper 1 本・27 か所） | `data-ww-theme` は撤去で消える。`data-ww-site` は今も、作品を表示している間だけ付く（OFF・緊急OFF・強さ 0% で外れる）。判定の中身は同じ。レトロテーマそのものを確かめる spec（extension・theme-visual・native-surfaces・live-youtube・creator-editor の1件）は2回目に書き直すか消すので、ここでは替えていない |
| `src/diagnostics/asset-runtime-host.ts` の監視の印を同じく替えた                                          | 計測用のホスト。製品のビルドには入らない（`ASSET_PROFILE` のときだけ）                                                                                                                                                                                                                                        |
| 撤去前の実物を fixture にした（`tests/fixtures/backups/`）                                                | 撤去後も、撤去前のバックアップと設定が読めることを確かめるため。`tests/backup-fixture-capture.spec.ts` が、`retro-theme-final` のビルドで1回だけ書き出した（`WW_CAPTURE_BACKUP_FIXTURES=1`）。撤去後は作り直さない                                                                                            |
| 計測のハーネスに `UI0C_FEATURES=off` を足した（`scripts/ui0c/marks.mjs`）                                 | 基準を「表示オプションを全部 OFF」で取るため。撤去後のビルドは、このキーを読まない                                                                                                                                                                                                                            |

fixture の中身（`tests/fixtures/backups/provenance.json`）：

- `pre-removal.wwbackup`：バックアップのページで書き出した実物。画像1枚の作品（`baseThemeId: 'retro'`）と、その原本。レトロテーマの設定は、すべて既定値と違う値（強さ 37%・粒子 55%・配色 210/40/70・窓の飾り OFF・粒子 ON・掲示板 OFF・小窓の色 ON）。制作モード ON
- `pre-removal-storage.json`：同じ時点の `chrome.storage.local` の全部
- `strength-zero-storage.json`：上と同じで、強さだけ 0%（スイッチは ON のまま）

### 足したテスト

| テスト                                | 確かめること                                                                                                                                                                             |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `backup-data.spec.ts`（unit）2件      | 撤去前のバックアップの JSON が読める。作品・スイッチ・制作モードが復元の対象になる。古い項目（強さ・粒子・配色・表示オプション）に不正な値があれば、今と同じくバックアップ全体を拒否する |
| `legacy-data.spec.ts`（e2e）3件       | 撤去前のバックアップを、原本ごと復元すると作品が出る／撤去前の storage のままで作品が出て制作モードが残る／強さ 0% の storage では何も出ず、強さを上げれば同じページで出る               |
| `base-theme-parity.spec.ts`（e2e）1件 | `baseThemeId: 'retro'` と `null` の作品で、作品の CSS・YouTube の部品に付く印・着せ替えの結果が同じ。ほかの名前の基底テーマは、今と同じく拒否される                                      |

- unit の側は、素材の検証（画像の読み込み）を Node でできないため、JSON の部分だけを読む。原本を含む復元は e2e で確かめる
- `base-theme-parity` の部品の印は、YouTube の本物の部品だけを比べる。レトロテーマが足した窓（タイトルバー・メニューバー）は自前の要素なので数えない。最初はこれを数えて失敗した。違いはこの2つの印だけだった
- 強さ 0% のテストの「何も出ない」は、読み込みの直後から2秒間、印と層が一度も現れないことを見る。そのあと強さを 37% にして同じページに出ることで、設定が読めていたことも確かめる。撤去の更新で OFF へ移したあとは、最後の手順を「作品を表示する」を ON にする形に替える（3回目）

### 計画書の訂正

計画書の「4」に「過去の計測の基準値はすべてレトロテーマ込み」と書いたのは誤りだった。計測のハーネス（`scripts/g11`・`scripts/ui1`・`scripts/ui0c`）は、どれも `baseThemeId: null` の作品で測っている。この作品ではテーマの CSS・変数・表示オプションが外れるので、過去の基準値にレトロテーマは入っていない。計画書を直した。
