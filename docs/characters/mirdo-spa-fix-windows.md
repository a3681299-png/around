# ミルドの検索 SPA と検証手順の修正

2026-11-07。修正前 `a1fe387`、修正後の製品コード `b46cedc`。中核は `src/sites/youtube-operations.ts`。DesignDocument の版は16のまま。中核の合否は Claude Code の独立検証へ引き継ぐ。

## 検索 SPA

変更前の同じビルドで、実 YouTube の視聴ページから、ミルドが50 px以上逃げた直後に検索した。着座あり／着座割り当てだけ外した回の各6秒の CDP CPU プロファイルでは、拡張自己時間が246.0／253.1 ms。50 ms以上の処理は8／7件。両方で `fixedContainingBlock` が自己時間の最大で69.0／83.2 msだった。主な呼び出し元は描画の `overlaySlot`、操作面の `capture`、プレーヤーの `beneathPlace`。座る設定を外してもこの費用は残った。

着座ありの自己時間上位は `fixedContainingBlock` 69.0 ms、`contextChain` 16.6 ms、操作面の変化の選別13.9 ms、別の MutationObserver のコールバック11.4 ms、`beneathPlace` 7.3 ms。着座の対照は作品の割り当てだけを変更し、アダプターの縁の取得は両方で有効。縁の取得 `captureGeometry` はいずれも上位に現れなかった。

オーバーレイの祖先が fixed の包含ブロックを作るか、操作面の探索・描画のスロット・プレーヤー面の検査で同じスタイルを調べ直していた。すでに積層の証明に使う `createDrawReads` の `containingBlock` を共有した。比較する CSS の条件と安全側へ戻す条件は同じ。キャッシュは既存の変更記録とタスク終了で無効になる。操作部品の検出、重なりの証明、押した瞬間の再確認は既存の経路で行う。

通常ビルドと同じ条件で、操作面の読み取り直後に重複するスタイル読み取りが0回になることを確認した。同じタスク内に祖先の transform が変われば操作面の読み取りは使えないと判定し、次のタスクでもスロットを取り直す。実 YouTube の画像でミルドと進捗バーが表示されることを確認した。

短い変更前後のプロファイルでは、`fixedContainingBlock` の自己時間88.4→80.5 ms、50 ms以上の処理8→7件、拡張の合計238.5→266.3 msだった。この1組は本計測と分けた。

## 動作判定の入力

退避した足固定前の19本は14本通過。足固定後の19本は16本通過し、このデスクトップと共有リポジトリの測定結果が全19本で一致した。版をまたいで判定が変わったのは Walk_Loop と Walk_Formal_Loop。旧ノート PC の「15本」に対応する入力や判定結果は共有履歴に残っておらず、当時の1本と差の原因は特定できていない。

再比較できるよう、判定レポートに Chromium の版と、実際に読んだ VRM・VRMA・測定 JSON の SHA-256 を残す。クリップの順序を固定した。測定 JSON が存在して壊れている場合はエラーにし、省略された場合と区別する。判定の閾値と式は従来どおり。

## 実サイトテストの待機

`character-import-live.spec.ts` は、初回と逃走後の両方で、行動が `rest`、下の縁、座り重み1、休みのクリップ、停止なしがそろうまで最大20秒待つ。その後の可視性・縁からの距離・ポインター直上での停止の検査を維持した。戻れない場合は待機の段階で失敗する。

実 YouTube の変更後のテストは1件通過。逃げる→戻る→休みのクリップに戻る順を記録し、初回と帰着後の両方で座り重み1。2,039コマで箱・座り重みの飛び0、ポインター直上404コマで停止0、落ち着いて座ったときの箱中心と縁の最大差0.016 px。

変更した判定ツールを旧・新の各19本で再実行した。VRM のハッシュは同じで、両方とも19本すべての VRMA・測定 JSON のハッシュを記録した。新版の測定値は共有の判定レポートと一致。判定に使った素材・画像・生プロファイルはローカルで扱った。

## Claude Code に確認してほしいこと

- 同じ描画内の読み取りの共有が、変更を挟んだときに古い CSS の結果を使わないこと。特にネイティブのプレーヤーを移すシアター・全画面・ミニプレーヤーと、CSS の変化で安全側へ戻る場面。対象は `operation-safety`、`operation-bands`、`operation-controls`、`layering`、実 YouTube の `character-import-live`。
- ノート PC で、実 YouTube の検索 SPA の長い処理・拡張 CPU 合計・動画落ちを同版対照と照合すること。以前の `c69d9bb`→`b3db85e` の比較は別の版間なので、今回の差と分けて扱う。
