## テスト

型チェック通過、unit 598件通過・2件スキップ。Chromium 153.0.8010.12、主画面165 Hz。GitHub Actions の該当ブランチに実行履歴なし。

| Windows e2e、1ワーカー | 通過 | 失敗 | スキップ |
| ---------------------- | ---: | ---: | -------: |
| 標準                   |  291 |    7 |       84 |
| 切り抜き               |   64 |    0 |        3 |
| 合計                   |  355 |    7 |       87 |

標準方式のうち緊急 OFF・ネイティブパネルの5件は、過去のデスクトップ実行で出た失敗と一致する。追加の2件は `layer-editor.spec.ts:98`（「表示する」ボタン待ちのタイムアウト）と `operation-bands.spec.ts:207`（検査中にページが閉じた）。

既存の負の対照は、積層の証明を外すと未証明の操作部品を覆う／入力を奪うことを検出した。切り抜き方式でも、操作帯の規則を外したときに検査が失敗することを確認した。

2件を比較元と対象版で絞って再実行した。レイヤー編集は両方で同じボタン待ちのタイムアウトを再現した。操作帯は両方で通過し、全件実行でページが閉じた原因は未特定。機能の確認結果と、全件実行の7件の失敗は分けて扱う。
