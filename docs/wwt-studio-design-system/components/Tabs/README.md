Switches between the sections of a narrow surface (side panel, in-page editor).

- Provide `ww-tab` buttons with `role="tab"` and `aria-selected`; at most five, inside `ww-tabs` (height `control`, on `surface-sunk`).
- The selected tab is `strong` `ink` with a G-pen stroke under it (84px, `pen` width), drawn in from its start in 4 frames when the tab is chosen. Others are `ink-muted`.
- In Studio the same sections are separate docked panels, not tabs.

Do not: use filled pill tabs, a uniform underline bar, or icons without labels.
