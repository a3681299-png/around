An on/off setting that applies immediately; use a checkbox (`ww-check`) inside lists and forms.

- Provide the label as text after the input, inside the `<label>`.
- The track is 32 × 20 (`control-dense`, `radius-pill`); the thumb moves in three frames (`steps(3)`).
- On: `cobalt` thumb and edge on `cobalt-wash`. Off: `ink-muted` thumb, `line-control` edge.

Do not: use a toggle for an action that needs 保存 to apply.
