A small labelled state; the word carries the meaning, the shape repeats it, colour comes last.

- Provide one short word or phrase. Pick the modifier by meaning, never by look: `--saved` (filled circle), `--dirty` (dashed circle), `--limited` (diamond, engine protection), `--advice` (triangle, not enforced), `--atmos` (ruled edge, atmosphere layer), `--off` (small dot, not available).
- Height `control-dense` (20), 12px text, `radius-control`.
- When the engine limits something, use `ww-notice` in the panel: the diamond, then what it protected and how to fix it, one sentence each.
- The save chip appears once per screen, in the header.

Do not: use `--limited` red or the diamond for anything but engine protection; show a chip with no word.
