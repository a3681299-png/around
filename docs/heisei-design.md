# 平成シルバー・ソフトウェアシェル

「機能美の時代に、遊び心を取り戻す」

## 今回のデザイン

- **シルバーで統一**: YouTubeがダーク表示でも銀色。以前の青紺のダークパレットは削除した。1〜100%は銀色の明暗と立体感を調整し、0%だけが元のYouTubeになる。独立した夜版は今後の別案。
- **直角の外装**: 動画、サムネイル、パネル、ボタン、アバターのクリップまで角を揃えた。元の動画や画像のピクセル、寸法、縦横比、フィルター、再生コントロールは加工しない。
- **小さなソフトウェアの窓**: 動画の上に現在の動画名を表示するタイトルバー、プレイヤー外周に寸法を変えない細い立体枠。既存プレイヤーを移動・再生成せず、タイトルバーだけを隣接配置する。再生リストにもタイトルバーと銀の外装、選択行には紺地と白文字を使う。
- **上半分の反射**: メインと小窓のタイトルバーは49%／50%で明暗を切り替える光沢。検索欄は凹型、ボタンは凸型。背景は落ち着いた銀色を保ち、装飾をコンテンツへ被せない。
- **画面上下で囲む**: 下端に26pxのステータスバーと液晶時計。端末のローカル時刻をHH:MMで表示し、読み上げを毎秒発火させない。非表示タブでは時計タイマーを止める。
- **文字の役割を分ける**: ソフトウェアのラベル、メニュー、液晶には同梱PixelMplus12を12px・400で使う。拡大変形、ぼかし、合成太字を足さない。動画名は読みやすいゴシック14px、再生ページ16px、コメント13px・400。長い小窓タイトルは省略表示し、全文は元のタイトルで読める。
- **オフラインのフォント**: 完全な日本語字形セットをWOFF2へ圧縮し同梱。外部フォントAPIを使わず、元のM+ FONT LICENSEと著作権表示を保持した。希少文字や絵文字はシステムへフォールバックする。DPIやブラウザーズームによるラスタライズの差は残る。

## 操作と境界

`window-chrome`の個別OFFでヘッダー、小窓の追加タイトルバー、ステータスバー、時計を一括解除する。全体OFF／0%ではテーマCSS、surface属性、フラグ、Observer、タイマーも撤去する。設定ボタンとその読みやすさのためのフォントは従来どおりOFFでも使える。

全画面では追加ヘッダー、動画タイトルバー、下部バー、装飾の余白とプレイヤー外周の枠を非表示にし、動画とネイティブ操作、設定パネルを使う。SPAや動画タイトルの文字ノード更新、プレイリストの選択変更に追従する。

色・影・グラデーション・寸法は`themes/retro/tokens.css`、見た目は`surfaces.css`／`chrome.css`／`editor.css`。YouTube固有セレクタ・挿入位置・ナビゲーション・タイトル読取は`sites`。既存の機能レジストリと個別設定を維持し、キリ番・カウンター・BBS・夜版は追加しない。

## 検証

自動検証と実サイト確認の区別は`verification.md`を参照。検証用サムネイルは合成テスト素材であり、実際のYouTubeやおすすめ一覧ではない。
