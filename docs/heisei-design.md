# 平成シルバー・ブルー

「機能美の時代に、遊び心を取り戻す」

## デザインの選択

- **銀色の筐体**: ベタな濃いグレーを、明るいシルバーと淡い青灰色へ。白い反射と1pxの影を使い、重い二重枠を減らす。
- **黒い液晶**: 小さなタイトルバーだけを黒くし、当時の音楽プレイヤーのような表示面を作る。細い水色の上端と静かな点灯表示を添える。
- **青いガラス**: 選択したカテゴリ、ナビゲーション、ホバー、設定スライダーに、二段の反射がある青のグラデーションを使う。
- **余白と文字**: セクション全体への強制的な余白をやめ、動画カードの周囲だけに薄い外装を付ける。日本語本文は一般的な読みやすいフォント、タイトルは600のウェイト。ドット風の等幅文字は飾りの小ラベルだけ。
- **遊び心の量**: `PERSONAL CHANNEL / 2003`と小さな顔文字に限定。動き続けるエフェクト、音、点滅、背景キャラクターは追加しない。
- **ダーク表示**: YouTube本来の設定に合わせて青紺のハードウェア風に切り替える。本文は明るく、補助テキストも読める明度を維持する。

参考画像からは「銀色の小窓」「液晶の黒」「青い空気感」を取り入れ、元のレイアウト・キャラクター・OSロゴは複製していない。

## 操作と所有範囲

既存の動画・サムネイルの画像データ、動画のCSSフィルター、再生操作のDOMは変更しない。カード外装と角丸はテーマの強さに従う。検索・コメントの入力と送信はサイト側に任せる。

追加バーは`window-chrome`機能として個別にON/OFF可能。全体OFF／0%では追加バー、スタイル、監視処理、surface属性、rootのフラグ／変数を撤去する。プレイヤー設定への入口は従来どおりOFFでも残る。全画面では追加ヘッダー分の余白をなくす。

色・影・グラデーション・寸法のトークンは`src/themes/retro/tokens.css`、表示ルールは`surfaces.css`／`chrome.css`／`editor.css`に分けた。YouTube固有のDOM判定とURLは`src/sites`内に置いた。

## 検証範囲

自動検証の結果と実行環境の制限は`verification.md`を参照。検証用HTMLに描かれたサムネイルは合成のテスト素材であり、実際のYouTubeやユーザーのおすすめ一覧ではない。
