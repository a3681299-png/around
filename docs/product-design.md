**R の番号（R1〜R9）は、製品の段階の番号である。** 長期のロードマップの「段階3〜12」や「G0〜G6」（[spatial-design.md](spatial-design.md) の11節）とは別の番号で、対応させて読まない。例えば R3（キャラの土台）は「段階3」とも「G3」とも関係がない。

## spatial-design.md との関係（変わった決定）

- spatial-design.md の4節は「最初のキャラは A（2D のパーツ変形）」（2026-10-23）としていた。**2026-11-03 の決定で、キャラは VRM（3D）になった。** 点・面・行動の契約（rig facts / behavior / instance state / frame、面との関係、接地の段階）はそのまま使う。A の素材契約（スプライト・差し替え）は今は作らない
- 「Around 内に rig エディターや IK の制作機能は作らない」は変わらない。R3 の IK は、触れる所を合わせる実行時の補正だけで、作者が編集する道具ではない

## キャラの形式と「中の形」

- キャラは VRM で読み込む
- エンジンの中では、**骨の対応・表情・揺れもの・材質を「中の形」で持ち、VRM に縛られない形にする**。R7 で FBX を取り込むとき、同じ中の形へ変換するため
- world と描画の判断は中の形だけを見る。VRM のライブラリの個体（`VRM` オブジェクト）は描画の中に閉じる

## 動きの3段階

| 段階            | どのモデルで   | 中身                                                                                                   |
| --------------- | -------------- | ------------------------------------------------------------------------------------------------------ |
| 1. 読み込むだけ | どの人型でも   | 視線と顔の向き、まばたき、呼吸、揺れもの、表情、横に揺れる、跳ねる、震える、瞬間移動、計算で作る座り方 |
| 2. 標準の動作   | 普通の体型     | 標準の .vrma と姿勢に、自動の補正（腰の高さ、足の接地、足の長さに合わせた速さ、腕の開き）              |
| 3. 作者の動作   | そのキャラだけ | そのキャラ専用に作った動作                                                                             |

- 読み込んだときに体型（頭の大きさと身長の比、足と腕の長さ）を測る。標準の動作が崩れる体型なら段階1の動きに切り替え、使う人に表示する。使う人が手で変えられる
- アニメーションは翔太が用意する。エンジン（Claude Code）が作るのは、再生と切り替えの仕組み

## 移り方

- **歩かずに移る。** 遠い所へは瞬間移動（ノイズが走って消え、別の部品に現れる）。近い所へは跳ねるか、縁の動作（よじ登る・飛び降りるなど）で移る
- 移る先はランダムではなく、きっかけ（カーソル、新しいコメント、動画の停止など）で選ぶ
- **部品の上を横切らない**

## 姿勢と触れる所

- 姿勢は 1コマの .vrma（人型の骨ごとの角度）と、「どこが何に触れるか」の印（お尻は縁、両手はひざ、足は床など）で持つ
- 使う人のキャラに同じ角度を当て、触れる所は IK で合わせ、体にめり込む所は少し押し出す。届かない所はあきらめるか、より単純な姿勢に切り替える

## 座り方は下に何があるかで分ける

| 座る所                 | 下にあるもの                         | 座り方                                               |
| ---------------------- | ------------------------------------ | ---------------------------------------------------- |
| 動画カード・ボタンの上 | 操作部品（重なった絵は切り抜かれる） | 体育座り・横座り・寝転ぶ。**縁より下に何も出さない** |
| プレーヤーの上の縁     | 動画                                 | 足を下ろしてぶらぶらさせる                           |
| ページの余白           | 何もない                             | 足を下ろしてぶらぶらさせる                           |

## 入力と操作性

- **キャラは入力を受けない**（本物のボタンが押せる）
- G1.2 のとおり、近づいた操作部品に重なる層だけが止まる。止まる代わりに「よける」のは後の段階
- 操作性の3段階（AGENTS.md）はキャラにもそのまま掛かる。キャラが操作部品を隠すことはエンジンが起こさせない

## 素材の扱い

- 翔太が用意した素材（トルーシェの VRM、比べる用の素体、.vrma 36本と manifest）は **リポジトリに入れない**。トルーシェは他の作者のモデル、動作は Mixamo 由来で再配布できない
- 開発と手元の確かめでは、パスを環境変数で指定して使う（`AROUND_VRM_FILE` と同じ形。R3 の計画 [r3-plan.md](r3-plan.md) で名前を決める）
- CI のテストでは、テストの中で作る簡単な人型と動作を使う

- 通過の条件：**トルーシェが動画カードに座る**
- 調べと計画は [r3-plan.md](r3-plan.md)
