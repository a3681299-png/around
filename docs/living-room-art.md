# 住む部屋の美術（2026-11-11、`feat/living-onboarding`）

**この文書は初版の記録。出窓・広い間取り・生活感・材質を改めた現行版は [living-room-realism.md](living-room-realism.md)。**

Claude Code。`codex/living-room`（`eca7c0a`）から。コンテスト用の独立した Web 作品の、最初の塊：キャラが暮らせる 3D の部屋そのもの。キャラとオンボーディング UI はこの塊に入れていない。

**中核は触っていない**（`src/renderers/three/room.ts` から `readLayout` を `room-layout.ts` に移しただけ。挙動は同じ）。作品データの版は上げていない。

## 1. 置き場所

| 物                          | 場所                                                                      | 備考                                                                             |
| --------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 部屋を作るスクリプト        | `scripts/living-room/`（`lib.py`・`10_shell.py`〜`80_bake.py`）           | Blender 5.2 の中で順に実行する。各スクリプトは自分のコレクションを消して作り直す |
| 編集できる Blender ファイル | `art/living-room/living-room.blend`                                       | モディファイアは残してある。焼いた複製は `bake` コレクション                     |

作り直し：Blender で `lib.py` → `10`〜`70` → `80_bake.py`、そのあと `node scripts/build-living-room.mjs`。

## 2. 美術の方針

- 夜、青紫が基調。冷たい光（モニター・月・LED・ネオン）と暖かい光（スタンド・床のアークランプ・電球の列）を対にして、青紫が単調にならないようにした
- 4.8m 四方。奥の壁と左の壁は高く、右は腰の高さの壁（カメラが上から覗くジオラマの切り口）。天井はない
- 机は奥の左（画面がカメラを向く＝一番の見せ場）、ベッドは奥の右の窓の下、本棚は左、手前の左にビーズクッションと床のランプ、右手前にチェストとギター。中央はラグだけで、歩く所と UI の余白にした
- 形は、面取り・曲面・厚みのある物で作る。クッション・枕・布団は細分化した面を膨らませ、布は式で垂らして折り目を付けた。箱を並べただけの仮の物は置いていない
- 質感は単色の材質と焼いた光。写実の質感の画像は使っていない

## 3. 描き方（自分で決めたこと）

| 決めたこと                                                                                                  | 理由                                                                                                                   |
| ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 光は Cycles で焼く。大きな面（床・壁・机の天板・ラグなど `lm` の印の物）はライトマップ 1 枚、ほかは頂点の色 | 小物まで 1 枚のライトマップに入れると解像度が足りない。頂点の色なら UV もテクスチャも要らない                          |
| Web の色＝材質の色 × 焼いた光 × `lightScale`（`room.json`）                                                 | ふつうの GLB のまま（独自の拡張なし）。光は 0〜1 に収めて書き、ページで倍率を戻す                                      |
| 光る物（`dyn_*`）は焼かず、自分の色で描いてブルームをかける                                                 | 画面・電球・ネオンがにじむ                                                                                             |
| 既存の `playground/room.ts`・`renderers/three/room.ts` の描画は使わなかった                                 | どちらもライトマップを 1024 に縮める・YouTube や作品データと結び付いている。部屋の読み取り（`readLayout`）だけ共有した |
| 止まっている間は描かない。ポインターで少し回り込む間だけ描く                                                | ノート PC の CPU と GPU を使わない                                                                                     |
| 外部の 3D 素材は使っていない                                                                                | Blender MCP の素材ライブラリは無効だった。すべてスクリプトで作った物なので、権利の確認が要る素材はない                 |

## 4. キャラと UI のための用意

- `navmesh_floor`：家具の足元を除いた床を長方形にまとめた物（`70_meta.py` の `OBST`）
- 座る：`marker_sit_chair`（机に向かう）・`marker_sit_bed`（ベッドの縁）・`marker_sit_beanbag`・`marker_sit_cushion`
- 隠れる：`marker_hide_beanbag`・`marker_hide_chair`・`marker_hide_dresser`（カメラから見て物の向こう側）
- 立つ：`marker_stand_window`・`_shelf`・`_center`・`_front`・`_guitar`
- 画面は `dyn_monitor_screen`・`dyn_monitor2_screen` を別のメッシュにしてある（あとで本物の UI を映せる）
- 目印の向きは glTF の +Z（Blender では物の -Y）。`readLayout` でそのまま読める
- ページのテスト用の入口（`AROUND_LIVING_TEST=1`）で、12 か所すべてが歩ける床の上にあり、歩いて届くことを確かめた（`room-life.ts` の `standPoint`・`walkable`・`floorPath`）

## 5. 確かめ方

- Blender：`art/living-room/renders/v0N_camera_main.png`（同じカメラ。v01 → v05）
- ブラウザー：`node scripts/living-room/capture.mjs <out.png>`（画面の外の窓、本物の GPU）。`web_v05`〜`web_v07`
- 参考画像（gogh の 2 枚）は会話に届いていなかったので、見比べは依頼文の言葉（青紫の夜・モニターの発光・壁の密度・正方形の広さ・家具の釣り合い）に対して行った。画像との見比べはまだ

## 6. 残っている美術の問題

- 窓の外：ブラウザーでは空がほぼ黒く、月のにじみが強い。Blender では空が白っぽい。どちらも夜景として弱い（空の頂点の色の書き出しを未確認）
- 布：布団と掛け物は式で作った形で、手で作った布のしわには届かない。布団の上に頂点の光のむらが少し残る
- 質感：焼いた拡散光だけなので、金属・ガラス・陶器の照り返しがない。木目や布目の模様もない
- 右手前：チェストが画面の端で切れ、ギターは影の中でほぼ黒い棒に見える
- 壁の上のほう（奥の壁の窓の上、左の壁の上）は情報が少ない。ラグの柄も単純
- Blender（AgX）とブラウザー（ACES）で明るさと彩度が少し違う（ブラウザーのほうが濃い）
- `room.glb` は 14.7MB（圧縮なし）。公開の前に meshopt などで縮める余地がある
- 重さ（GPU の時間）は測っていない。止まっている間は描かない作りにしてある
