The timeline, drawn as an animator's timesheet: 12px per frame, one track per layer.

- A `around-sheet` is a 212px name column (aligned under the layers panel) and the tracks. The corner holds the play button, the frame count (`K024 / K096`) and the rate (`12fps`) in mono; the ruler counts frames every 8.
- Tracks are `control-dense` (20) tall. Keys are 8px squares in `pen-bone`; the selected key fills with `cobalt`. A hold is a `pen-bone` bar at 22%.
- The playhead is a ruled 1.5px `cobalt` line.
- When the driver is not time (scroll, mouse), the ruler shows that signal's range instead of frames, in the same mono style.

Do not: use diamonds for keys (the diamond means 制限中); use smooth curves as the default view; colour keys by layer.
