## D14②

`740b79b` の差分は `operation-safety.spec.ts` のみ。スクロールだけの区間は40フレームから 666.67 ms、移動後の探索は最大60フレームから最大1,000 ms になった。移動検出時の早期終了と、全体の読み取り0、グループ数1より大、グループの順序、検出時間 `0 ≤ found ≤ 200 + (groups + 2) × longest` の期待値は同じ。 [差分](https://github.com/a3681299-png/around/commit/740b79bd9a944640f2e8c29fd3a7e5314baaf685)

| 主画面の設定 | Chromium の rAF 中央値 | 守りあり（重なり／切り抜き） | グループ内の比較を外した版 |
| ------------ | ---------------------: | ---------------------------- | -------------------------- |
| 165 Hz       |                 6.1 ms | 2/2 通過                     | 2/2 が意図どおり失敗       |
| 60 Hz        |                16.7 ms | 2/2 通過                     | 2/2 が意図どおり失敗       |

画面外の表示ありで、描画の周期を各テストのページで観測した。故障注入は、一時バンドルでグループ内の操作部品の照合だけを省き、巡回とログを残した。両方式・両周波数で、前段の期待値は通ったが、移動したリンクが見つからず `found = -1` で失敗した。

## 性能

Ryzen 5 5600X、Radeon RX 6800／D3D11、Windows 11 Pro 26H2（26300.9711）、Chromium 153.0.8010.12。表示あり・画面外（−4000, 0）、1920×1080・DPR 1、主画面は60 Hz。各ブラウザーで実 GPU と約16.7 msの rAF 周期を確認した。

同じ未ログインの種プロファイルから各側を複製し、同じ拡張 ID で計測ビルドだけを切り替えた。公開の自律マネキン1体。奇数組は A→B、偶数組は B→A。起動は実動画へのナビゲーションから6秒。定常は6秒待ってからカーソルをプレーヤーに毎秒出し入れする6秒。検索 SPA はマネキンが50 pxより大きく移動したことを見てから、検索欄で `lofi` を送信した後の6秒。 [視聴ページ](https://www.youtube.com/watch?v=LC1a-DwUhls)

`7351884` の手順から観測用ラッパーを組み直した。g11 単独の拡張 rAF コールバック経過時間には同期 DOM 処理を含む。CDP は別の組で500 μs間隔の V8 サンプルから拡張 URL の自己時間を合計。g11 の1フレーム値はコールバックのあるフレーム、CDP の1フレーム値は拡張サンプルのないページの rAF も0として含む。50 ms以上の処理はページの Long Tasks API、動画は同じ要素・ソースの `getVideoPlaybackQuality()` の差分。検索 SPA での動画の採取は元の動画が外れるまで。g11 の校正は2 msの負荷追加に対して中央値 +2.00 msだった。 [A/A の方法と振れ幅](https://github.com/a3681299-png/around/blob/7351884/docs/tooling.md)

広告、モデル未描画、動画フレーム未取得、6秒窓の遅延、CDP の記録区間不足は除外し、その場面の両側を同じ順序で取り直した。遷移前の逃走は検索の全採用窓で確認した。遷移開始後に守りがキャラを隠すことは計測対象に含めた。背景 CPU はブラウザー起動前の700 msを参考値として記録し、組の除外条件には使っていない。準備時の別種プロファイルとラッパーの参照エラーによる試行は本計測に含めていない。

CDP の起動計測は遷移前に開始したが、実文書がコミットされるときに記録の起点が切り替わる。初回の採取では6秒窓の先頭から1.2秒以内かつ最初の拡張 rAF より前から記録していることを確認した。補充の採取では固定の1.2秒を、実文書の `domInteractive` より前に置き換えた。記録が拡張の `document_idle` での実行より前に始まったことを、応答に時間がかかった窓でも確認するため。以前に除外した窓は再採用していない。
