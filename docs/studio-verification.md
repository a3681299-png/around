# 独立Studioの操作と検証

2026-10-18。`codex/creator-editor-spike` の専用worktreeで実装した。構造と移行方針は [studio-foundation.md](studio-foundation.md) にまとめている。

## 起動と制作

1. `.work/creator-editor/dist` をChromeの「パッケージ化されていない拡張機能を読み込む」で読み込む。更新時は拡張とYouTubeを再読み込みする。
2. YouTubeを開き、テーマON・強さ1%以上にする。拡張Popupの「Studioを開く（別ウィンドウ）」を押す。
3. Studio上部で対象のタブ名とIDを確認する。複数タブがある場合は一覧で選ぶ。対応タブを後から開いた場合は「タブを更新」を押す。
4. 左から素材を追加。チェックで複数選択し「選択をグループ化」。右のプロパティでマスクや振る舞いを変更する。実際のプレビュー・選択・ドラッグ・拡縮・回転はYouTube上で行う。
5. 保存すると各YouTubeタブに反映する。破棄は最新保存値へ戻す。Undo/RedoはStudioとYouTubeで同じ履歴を使う。

StudioとYouTubeを並べて使う。「YouTubeを表示」は対象のウィンドウを手前にする。キャンバスをiframeへ埋め込まない。サイト内の「デザインを編集」や、接続中の「クイック編集を表示」も同じ編集セッションを開く。

レイヤーとプロパティは同時表示できる。「左右を入れ替える」、一覧の幅を変える区切り、切り替え表示、使い方タブ、折りたたみを用意した。Studioの配置・幅・表示領域・プロパティの開閉をUI設定として保存する。作品のUndo履歴には入れない。

Ctrl/Shiftで複数選択、矢印で1px・Shiftで10px移動、Ctrl+Dで複製、Deleteで削除、Escで選択解除、Ctrl+Z/Shift+Z/YでUndo/Redo。MacはCtrlの代わりに⌘。入力欄ではエディターのショートカットを実行しない。

## 実YouTubeで確認した範囲

ログアウト状態の実YouTubeを、専用プロファイルのChromiumとMV3拡張で検証した。ページ差し替えはしていない。次の6項目が成功した。

1. Popupから別Studioを起動し、画像3枚を読み込んで、マウスだけでグループ化。
2. YouTube上でグループをドラッグし、Studioに反映。StudioのUndo/RedoがYouTubeの同じ操作を戻す。
3. グループの円形マスクとマウス追従、動画の一時停止によるフェード。
4. 保存、YouTube再読み込み、Studio再読み込みから再接続し、同じ作品・選択・マスク値を復元。
5. 接続解除後のクリック透過と実際の動画再生操作、YouTubeロゴからHomeへのSPA遷移、再接続。
6. テーマOFFで描画・編集属性・接続バッジを撤去し、Studioの編集を停止。

実行は `WW_LIVE_STUDIO=1 npm test -- tests/studio-live.spec.ts`。確認記録は `.work/verification/studio-live.json`、画面は `studio-live-workspace.png` と `studio-live-youtube.png`。最終のfixture回帰は `.work/verification/studio-final-targeted.log`、全体は `studio-all.log` に保存した。これらは作業環境の検証成果物で、Git管理には含めない。

実YouTubeで、独立Studioからの全アニメーション形式、32レイヤー、複数Studioの競合、シアター／全画面、ブラウザー再起動までは今回確認していない。通常表示・fixture上の既存機能の結果とは区別する。普段のChromeプロファイルやログイン済み環境も未確認。

## 互換性と制約

- DesignDocument v7、既存形式の移行、asset ID、World Runtimeを変更していない。元の素材を重複保存しない。
- Chrome権限は `storage` のみ。mainと通常版distは変更していない。通常版distの12ファイルは作業前とSHA-256が一致した。
- 作品の保存先は従来のサイト単位。同じタブのStudioは一つまでで、共同編集・競合の自動マージはない。
- 未保存の復旧は同じ対象タブとブラウザーセッション内。ブラウザーを終了する前に作品を保存する。閉じた対象のドラフトを新しいタブへ移送するUI、オフライン制作は未実装。切断時の未完了コマンド・素材読み込みは再実行しない。
- 復旧checkpointは1対象6MiB以下、`storage.session` 全体の容量にも従う。保存に失敗した場合は通知し、作品の保存済みデータを消さない。Undoの最大100操作と既存の素材上限は維持した。
- レイヤー／プロパティの配置切替、一覧幅、表示切替と折りたたみに対応する。任意位置へ浮かせるパネルや、自由なドック分割は次段階。
- Studio中央は素材棚と接続案内。実サイトの映像を転送して描くプレビューではない。通常のYouTube操作に戻すには、クイックUIも終了する。
