# Playground のデスクトップ

2026-11-08。3D 版 `0f0f3b4` から、デモの「デスクトップへ」と「デスクトップで暮らす」の入口をつないだ。

## 手元で触る

ブランチ `codex/playground-desktop` のチェックアウトで実行する。昼のテスト部屋を使う例。

```powershell
$env:WW_PLAYGROUND_PRIVATE_ASSETS = 'C:/wwt-private'
$env:WW_PLAYGROUND_LOCAL_ROOM = 'C:/wwt-private/room/packed/room-packed-noon.glb'
$env:WW_PLAYGROUND_LOCAL_LAYOUT = 'scripts/playground/desktop-layout-noon.json'
$env:WW_PLAYGROUND_OUT = '.work/desktop-preview'
npm run build:playground
node scripts/playground/serve.mjs .work/desktop-preview
```

[Playground](http://127.0.0.1:4173/) で「WWT を適用」し、再生してから「デスクトップへ」を押す。デスクトップで再生・シーク・音量・検索を試し、ブラウザーの戻るかタスクバーの「ブラウザーに戻る」で復帰する。[デスクトップを直接開く](http://127.0.0.1:4173/#desktop) こともできる。直リンクからの復帰はタスクバーを使う。

昼の部屋の原本はローカル確認用の `.work` 出力にだけ含める。原本の展開先がないデスクトップでは、同じ SHA-256 のローカル LFS オブジェクトから読んだ。部屋の指定を外すと簡易の部屋で動く。

## 配置と動き

- 作品の配置は `scripts/playground/desktop-layout*.json` に置いた。モニターの中心・向き（度）・幅と高さ、床の Y、立って見る位置と経路を変更できる。位置と寸法の単位は Playground の3D座標。外部の部屋には原点・向き・倍率も渡す。値は実行時にも範囲を検証する。DesignDocument は v16 のまま。
- カメラの移動は約1.15秒。初めは距離と焦点距離を同じ割合で増やして窓の大きさを保ち、後半で窓を左に縮める。上下と横移動の補正は投影の中心をずらして出す。昼の部屋は、椅子の向こうのモニターと足元の両方が見えるよう、カメラを左へ寄せた。
- ミルドは下の縁を定位置にし、ポインターが近づくと一度消えて上の縁に現れる。脚を縁の受けに合わせた姿勢から座り、下の縁が空いたら戻る。デスクトップでは窓の縁から短く降りて、床を歩き、モニターに向いて立つ。動きを減らす設定ではカメラを短いフェードで切り替え、ミルドを所定の位置に置く。
- 基本版の3D描画は VRMA と評価済み姿勢が揃うまで最初のキャンバスを空にする。Playground の空間版も、最初の座りを骨へ反映してから表示する。VRMA の応答を止めた試行では、従来の基本版は T ポーズで、修正後は待機中に姿がなく、解除後の最初の姿が座りだった。

## モニターと描画

Chrome の HTML-in-Canvas では、窓と部屋のモニターが同じ HTML テクスチャを読む。動画は同じ `video` の `VideoTexture` を共有する。入力座標は手前の窓に同期する。モニターが読むのは部屋を合成する前の UI なので、映り込みは1段。CSS3D では同じ射影を実際の DOM へ適用し、部屋のモニターは動画を表示する。WebGL が使えない基本版にも、同じ動画を映す軽いモニターがある。 [Chrome の HTML-in-Canvas と WebGL](https://developer.chrome.com/docs/web-platform/html-in-canvas/webgl)

UI はブラウザーの paint、動画は新しいフレームに合わせて更新する。カメラが止まった後は部屋の色と深度を再利用するので、ミルドが家具の後ろを通るときも部屋のジオメトリを描き直さずに済む。ミルドと動画が止まり UI が静止した後は描画を休む。

ブラウザー画面の前後比較は簡易の部屋、Chrome 157、同じ動画で4組。定常 CPU の組差中央値は 0／+0.20 ms。定常 GPU の p95 は前0.673〜0.785 ms、後0.732〜0.855 ms、動画落ちは両版0/108。起動時の rAF CPU は初回が振れたので、適用直後の速度の合否には使っていない。

場面5の前・途中・後、場面6の視聴、直リンク、戻った画面を撮影した。窓のネイティブ再生・シーク・音量・検索を操作し、戻った後に同じ動画要素・停止位置・音量と検索結果を確認した。昼の部屋では椅子がモニターの右端に少しかかり、ミルドは経路の途中でローテーブルの奥に隠れる。机の前面の焼き込みには元の斑が残る。カメラの引き具合と、モニターとミルドの位置は本番の部屋で見直せる。
