# mainへのマージ時に反映するREADME下書き

依頼GではREADMEの既存の読み込み先案内を置き換えない。以下はマージと移行確認後の差し替え案。ショートカット・制作モードの使い方だけは、実験ブランチのREADMEにも追記する。

## 読み込み方・開発手順の差し替え案

Chromeへ常用として読み込むフォルダーは、通常版の既存パス C:\Users\sm787\GitHub-Projects\web-world-themes\dist に揃えます。既存カードを再読み込みしてください。別フォルダーを新規読み込みすると拡張IDが変わる場合があります。

実験版から移すときは作品とテイクを保存し、「作品と設定のバックアップ」から1ファイルへ書き出します。通常版で復元・画面を確認するまで、旧拡張・フォルダー・Chromeプロフィールを削除しないでください。[移行手順](extension-consolidation.md)と[バックアップ](extension-backup.md)に、戻し方と衝突時の扱いを記載しています。

設定画面先頭の「エディターを開く」から制作画面を開けます。制作モードONなら拡張アイコンから直接開きます。エディター内の「表示設定」から設定に戻れます。Alt+Shift+Eは制作モードに関係なく使えます。chrome://extensions/shortcuts でキーを変更できます。

開発・自動テストは隔離worktreeとテスト用Chromeプロフィールで行います。ビルドは .work/test-dist 等へ出力し、常用Chromeへ登録しません。常用distはmainでの検証とバックアップ確認後に更新します。

## 差し替え対象

- 「実験worktreeのdist」「このworktreeのdist」「実験版は.work/creator-editor/dist」等の散在する常用先案内をまとめる。
- 「権限はstorageだけ」を実際の storage / sidePanel に合わせる。依頼Gで権限は増えていない。
- Popupの複数の起動ボタンを主導線とする案内を、先頭ボタン・制作モード・ショートカットへ変える。従来の開き方は補足に残す。
- バックアップなしで旧拡張を削除する手順は入れない。
