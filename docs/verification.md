## 実際のYouTube

既存のブラウザーで検索欄とサムネイルの現在のDOM構造を読み取り、新しい`yt-searchbox`と`yt-thumbnail-view-model`に対応しました。セレクタはすべてYouTube用Adapterに置いています。

さらに、ユーザーのプロファイルから独立した、未ログインのChromiumへ実拡張機能を読み込んで確認しました。この確認ではページHTMLを差し替えていません。

動画のダウンロードと再生は検証時に止めました。プレイヤーの再生機能、ログイン状態での全画面、Shorts、会員向け画面、地域差やYouTubeの全A/Bテストまでは確認していません。YouTube側の変更があれば、Adapterの対象を見直します。

## 手動確認の手順

1. `npm run build`で生成した`dist`をChromeへ読み込み、YouTubeを再読み込みする。
2. PopupでONにし、強さを0%、60%、100%へ動かす。
3. ホーム → 検索結果 → 動画ページへ移動し、背景や角丸が維持されることを確認する。
4. スクロールで追加されたサムネイルにも適用されることを確認する。
5. YouTubeのライト・ダークを切り替え、文字と背景が読めることを確認する。
6. OFFで元の見た目へ戻り、YouTubeの操作が使えることを確認する。
7. Popupを閉じて開き直し、Chromeも再起動して、設定が残ることを確認する。
