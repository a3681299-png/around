# 部屋での暮らし：家具の柔らかさ・スマホとイヤホン・画面の光（2026-11-12、ノート PC、Claude Code）

`feat/living-onboarding`。フェリスが部屋で生活しているように見えることを目指し、[living-body.md](living-body.md) の身体の上に、次の3つを足した。

1. ベッドと椅子が、体の重みと勢いで沈み、たわみ、揺れて戻る
2. スマホを手に取り、イヤホンを自分で付け外しし、ベッドで寝転んで・椅子に座って使う
3. スマホの画面が光り、その光が顔・髪・手元と、枕・布団・机に届く。色は画面の中身で変わる

汎用の物理エンジンは作っていない。どれも「ばね」と「骨の向き」と「決まった段取り」の組み合わせで、毎フレームの処理は軽い（下の「負荷」）。

## 1. 分け方

| 部品             | 置き場所                                                                                          | 中身                                                                                                                                                                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 寝転ぶ段取り     | `src/characters/approach.ts`（足した）                                                            | 席の代わりにベッド（`Seat.lie`）を渡すと、横まで歩く → 向きを合わせる → 飛び込む（`dive`）→ うつ伏せで脚をパタパタ → 寝返りして仰向け（`lie`）→ うつ伏せに戻って起き上がる（`rise`）。体への指示は `lie`（倒れ具合）・`roll`（仰向け）・`kickLegs`・`landed` |
| スマホの段取り   | `src/characters/phone-routine.ts`（新規）                                                         | 取る・持ち上げる・左手でイヤホンを左右の耳へ・見る（親指のタップ、ときどき両手）・外す・下ろす・置く、と「手に持ったまま運ぶ」（`carry`）。手の行き先は名前（置き場・顔の前・イヤホン・耳）で返し、ページが部屋の座標にする                                  |
| イヤホンのコード | `src/characters/cord.ts`（新規）                                                                  | 本体から分岐まで1本、分岐から左右の耳へ2本。点と長さの制約（Verlet）、重力・空気抵抗・下の面との接触。1/120 秒の固定刻み                                                                                                                                     |
| 椅子のばね       | `src/living-room/chair-give.ts`（新規）                                                           | 座面の沈み・背もたれのたわみ・椅子全体の揺れ、の3つのばね。座り込んだ瞬間に打ち込む                                                                                                                                                                          |
| 椅子の表示       | `src/living-room/chair-rig.ts`（新規）                                                            | 部屋の `tex_chair` のシェイプキー（`seat_sink`・`back_recline`）とベースを中心にした傾きに、ばねの値を当てる                                                                                                                                                 |
| ベッド           | `src/living-room/soft-surface.ts`（広げた）                                                       | 座りは1点、寝転びは7点（胸・腹・腰・太もも・膝・両前腕）で押す。点ごとに重みを持ち、脚を上げた膝は浅く沈む。枕も柔らかい面に入れた                                                                                                                           |
| 画面の光         | `src/living-room/screen-glow.ts`（新規）・`resident.ts`                                           | 部屋の焼いた面（光を持たない材質）に、画面の位置・向き・色から光を足すシェーダーの追加。キャラには画面の少し後ろから当てるスポットライト                                                                                                                     |
| スマホの見た目   | `src/living-room/phone-prop.ts`（新規）                                                           | 本体・画面（流れるフィードを自分で描く）・イヤホン2つ・コードの管                                                                                                                                                                                            |
| 1日の流れ        | `src/living-room/life-script.ts`（のちに削除。[living-mind.md](living-mind.md) の心に置き換えた） | 机 → スマホ（イヤホン）→ 持ったままベッドへ → 寝転んで見る → イヤホンを外す → ベッドに置く → 机へ → またベッド → スマホを取って持ったまま机へ → 机で見る → 机に置く、の繰り返し（約 2 分半で一周）                                                           |
| 体               | `src/renderers/three/living-body.ts`（足した）                                                    | 2b 寝転ぶ姿勢（うつ伏せと仰向けの混ぜ合わせ、脚、置き方）、4c 両手で持つ IK（手のひらと指の向き、指を握る、右親指のタップ）、影をベッドの上に、`hand()`・`head()`                                                                                            |

部屋のデータ（`scripts/living-room/`）：

- `reference_models.py`：椅子にシェイプキーを2つ作る（座面の輪郭の中を中央ほど深く 4cm、縁はわずかに盛り上がる／背もたれを付け根の軸で後ろへ最大 13°、上ほど大きく）。`soft` の印を付ける
- `80_bake.py`：`soft` の印の物は形を評価せず（シェイプキーが消えるため）そのまま写し、別のメッシュとして光を焼いて、シェイプキー付きで書き出す（`export_morph`、位置だけ）。`room.json` の `texturedMesh` を `tex_` にした（`tex_models` と `tex_chair` の両方）
- `reference_meta.py`：`pose_lie_bed`（寝転ぶ胸の位置と頭の向き）、`pose_phone_bed`・`pose_phone_desk`（スマホの置き場）を足した。机の置き場は上から光線を当てて平らな所を探す（Tripo の机の天板は平らでない）
- `reference_desk.py`：椅子に掛けていたパーカーを外した（椅子が揺れて曲がると、焼いたパーカーだけ宙に残るため）
- ベッドの上のノートとヘッドホンを、寝転ぶ場所から外した

## 2. 決めたこと

| 決めたこと                                                      | 理由                                                                                                                                                                                     |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ベッドは「うつ伏せで飛び込む → パタパタ → 寝返りして仰向け」    | 部屋のカメラは高い所からベッドの足元側を見ている。うつ伏せのままでは顔とスマホの光がカメラから隠れる（実画面で確かめた）。仰向けでスマホを顔の上に掲げると、光が顔と枕に落ちるのが見える |
| キャラへの画面の光は、画面の 0.4m 後ろからのスポットライト      | 画面の位置の点光源は、数 cm 先のスマホを持つ手を白く飛ばし、顔には届かない（実画面で確かめた）。後ろから広い円錐で当てると、手と顔がほぼ同じ明るさになる                                 |
| 画面の平均色は、描いたものの色と面積から計算する                | `getImageData` で読み戻すと GPU を待つ。CPU プロファイルで、スマホを使っている間の体の処理の約4分の1がこれだった（下の「負荷」）                                                         |
| 部屋への光は、焼いた色を「面の色合い」に直してから掛ける        | 焼いた色は光と色が混ざっている。明るさを中くらいに揃えた色合いに画面の色を掛けると、白い枕は明るく、暗い机はかすかに光る                                                                 |
| 光のスロットは2つ                                               | 1つはスマホ。もう1つは、オンボーディングの大きな UI を開いたときの主役の光のために空けてある（`screenGlow().set(1, …)`）                                                                 |
| 椅子の揺れに、座っている腰も乗せる                              | 揺れの回転を座面の点に当てて腰の位置にする（`chairRig().carry`）。体は傾けない（小さい揺れでは不自然に見えなかった）                                                                     |
| UI の目印が出たら、スマホは持ったまま（使わない）で目印へ向かう | 腕の取り合いを避ける（触れる腕が優先。`hold` を外す）                                                                                                                                    |

## 4. 確かめた結果（ノート PC、Chromium 画面の外・本物の GPU、144Hz）

録画・画像は `C:\wwt-private\Felis_v0.8.1\work\living-life\`（リポジトリの外）。

- 一周（約 160 秒）を通して止まらない。エラー 0。段取り：机 → スマホ（取る・持ち上げる・イヤホン左右・見る）→ 持ったまま立つ → ベッドへ → 飛び込む → うつ伏せでパタパタ → 寝返り → 仰向けで見る → イヤホンを外す → ベッドに置く → 起き上がる → 机 → 再びベッド → スマホを取る → 持ったまま机へ → 机で見る → 机に置く
- 椅子：座り込みで座面が 1.55 まで沈んで（行き過ぎ）戻り、背もたれが 0.72 まで反り、椅子が 0.06 rad 揺れて 1 秒ほどで止まる（連写で確認）。足は床
- ベッド：飛び込みで布団が打ち込まれて跳ね返る。仰向けで寝ている間、7 点で沈む
- 光：仰向けでスマホを顔の上に掲げると、顔と髪が画面の色で照らされ、枕と布団に柔らかい光が広がる（引きの画でも読める）。画面の中身（カードの色）で光の色が変わる

## 6. 残り・気になる所

- イヤホンの左右の粒は、フェリスの髪に隠れてほとんど見えない（耳の位置は頭の左右 5.6cm）

- 寝返りと起き上がりは、体全体を回すだけの動き。手で布団を押す・膝を立てて起きる、といった途中の姿はない
- 仰向けの脚は2つの決まった姿勢（片膝を立てる・もう片方を組んでぶらぶら）。長く見ると単調
- コードは細く（直径 2.4mm）、部屋のカメラからはほとんど見えない。近景用
- 椅子に深く座ると、背の高いエグゼクティブチェアの背もたれがフェリスを隠す（部屋のカメラは椅子の後ろから）
- 机の上でスマホを使うとき、画面の光は机とフェリスの前面に当たるが、カメラからは椅子の陰
- 表情：タップのたびに3割の確率で 1.6 秒笑う。画面の中身と結びついた表情（驚く・眠そう）はない
- うつ伏せで手に持ったまま飛び込む（スマホを持って移ったとき）と、腕を上げる飛び込みの演技とスマホを持つ手がぶつからないよう、飛び込みの間は手を自由にしている（スマホは手に付いたまま）
