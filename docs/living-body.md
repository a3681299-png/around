# 自然に動く体（Living Body）（2026-11-11、`feat/living-onboarding`、デスクトップ PC）

少ない動作（待機・歩く・座る3本）を、ブレンド・IK・計算の動きでつなぎ、状況に応じて動く体を作った。動作を1つずつ手で作らない。キャラはフェリス（手元の素材。リポジトリに入れない）。

**中核を触った**：`playwright.config.ts`（unit の一覧に `living-body` を1行）。`src/world/` は読むだけで変えていない。作品データの版は上げていない。

## 1. 分け方

| 層                 | ファイル                                  | すること                                                                                                             |
| ------------------ | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 行動（何をするか） | `src/characters/approach.ts`（純粋）      | 気づく → 歩く → 向く → 手を伸ばす → 戻る、席へ歩く → 座る → 立つ。立つ場所・見る点・手の行き先・座り具合を数値で出す |
| 移動（どう進むか） | `src/characters/locomotion.ts`（純粋）    | 先に向きを変える、加速・減速、角を回る、点の上で止まる。1/120 秒刻みなので FPS に依らない                            |
| 足（床に留める）   | `src/characters/foot-plant.ts`（純粋）    | 床に着いた足を、その場所と向きに留める。体が離れすぎたら小さく1歩踏み直す（片足ずつ）                                |
| 体（どう見せるか） | `src/renderers/three/living-body.ts`      | 下の順で毎フレーム姿勢を作る。VRM の正規化した骨だけを触るので、骨格の違いに依らない                                 |
| ページ             | `src/living-room/resident.ts`・`index.ts` | 読み込み、キャラだけに当たる光、目印（仮の UI）、クリックで目印を置く、テスト用の入口                                |

既存の物：床と経路は `room-life.ts`（`floorPath`・`nearestFloor`・`walkable`・`standPoint`）、IK は `two-bone-ik.ts`、読み込みは `verified-source.ts`・`vrma-clip.ts` をそのまま使った。`room-resident.ts`（拡張の部屋の住人）は変えていない。

## 2. 毎フレームの順番（`living-body.ts`）

1. **動作**：待機と歩きを速さでブレンド。歩きの位相は「進んだ距離 ÷ 歩幅」で進める（時間ではない）ので、歩き出し・巡航・止まり際のどこでも足が床の速さに合う。座る3本は、行動の求めに向けて重みをなめらかに移す
2. **姿勢**（足し算）：呼吸、立っている間の重心の移り、加減速での前後の傾き、曲がる向きへの傾き、視線（目は VRM の look-at、頭 55%・首 30%・胸 15%、左右 ±66°・上下 ±32° まで）
3. **足**：`foot-plant` が出した補正へ、両脚を two-bone IK で解く。留めた足に脚が届かないときは腰を下げる。足は床より下に行かせない
4. **腕**：手を目標へ（指先が目標に来るように、手首を前腕に沿って手の長さだけ手前に置く）。遠いときは上体を倒し、腰を少し引く。ひじは伸ばし切らない（97% まで）
5. **モデル**：VRM が自分の骨へ写し、髪・耳・尻尾・袖・紐が揺れる

時計は1つ（ページの dt。0.1 秒で頭打ち）。なめらかにする所はすべて `1 - exp(-rate × dt)` の形。

**はまった所**：three.js のミキサーは、ブレンドの結果が前のフレームと同じ骨を書き戻さない。2〜4 で骨に足した分が、動作が止まっている骨で毎フレーム積み重なった（足が暴れた）。フレームの最初に、この処理が触る骨を「動作が最後に与えた値」へ戻してからミキサーを回す。

`retarget_vrma.py` で 19 本を当てた（デスクトップで約 9 分）。使っているのは 5 本。

## 7. 残っている不自然な所

- **待機の腕が開き気味**：`Idle_Loop` の腕に、袖が太いので胴を避ける開き（12.5°）が足されている。立ち姿がやや固い
- **止まったあとの足幅**：歩きの途中の位置で足が留まるので、広めに開いたまま立つことがある（8.5cm 以上ずれたときだけ踏み直す）
- **歩き出しの最初の1歩**：歩きの位相を選んでいないので、どちらの足から出るかは成り行き。予備動作は「先に見る → 向く → 前に傾く」だけ
- **方向転換**：踏み直しは片足ずつの小さな歩み。大きく回るとき（120° 以上）は歩数が多く、やや小刻み
- **座る**：ベッドでは脚が布団の側面に少し入る。椅子・ビーズクッション・座布団は未確認。座っている間の手は動作のまま
- **腕**：手首の向きは前腕に沿わせるだけ（手のひらを面に合わせない）。肩（鎖骨）は動かしていない。袖で手が隠れる
- **干渉**：歩く経路は床の形で家具を避けるが、手や尻尾が家具に入るかは見ていない
- **重さ**：モデルは 55,043 三角形・10MB のまま。キャラがいる間は毎フレーム描く（ページが隠れている間は止める）。GPU と CPU は測っていない
- **表情**：動かしていない（VRM には 13 入れてある）

## 8. 自分で決めたこと

| 決めたこと                                                             | 理由                                                                                   |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 新しい純粋な処理は `src/characters/` に置き、`room-life.ts` は変えない | `src/world/` は中核。今回は身体制御の基礎で、生活の行動への組み込みは次                |
| 触れるのは `Interact` の動作ではなく IK                                | 目標の座標で動きが変わること、が今回の条件                                             |
| 方向転換の動作を作らず、足の踏み直しで代える                           | 動作を増やさない方針。足りなければ専用の動作を足す余地はある                           |
| キャラの素材はビルドの環境変数で渡し、`.work` の出力にだけ入れる       | 規約が未確認の素材が、公開する `dist-living-room` に入らないように（指定すると止める） |
| 録画と画像はリポジトリに入れない                                       | フェリスが写っている。規約が確認できたら `docs` に載せる                               |

## 9. アニメ的な演技（2026-11-11、2回目）

`7110e82` の動きは、速さも間も一定で「ゲームの NPC」に見えた（気づく 0.75 秒・一定の速さで回る・0.64m/s で歩く・同じ調子で止まる）。予備動作・緩急・時間差・誇張を足し、同じ「目印に触れる」を気分で演じ分けるようにした。**中核は触っていない**（`src/world/room-life.ts` の `draw` を読むだけ）。作品データの版も上げていない。

**参考について**：ゼンレスゾーンゼロの猫又、ブルーアーカイブのカフェ、Alan Becker の動画は、取得して見ることができなかった（見たことにしていない）。アニメーションの12原則のうち指定された7つを、下の表のとおり当てはめた。

### 気分（`approach.ts` の `Mood`）

| 気分               | 演じ方                                                                                                                                                                                                                                |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 普段（`calm`）     | 0.85 秒ほど見てから、少し沈んで歩き出す。歩きの動作より少し遅い（0.54m/s）。向きを変えてから進む。ゆっくり手を出す。何もないときは、ときどき部屋を見回す                                                                              |
| 興味（`interest`） | 耳が立ち、目と頭がすぐ向く（0.5 秒の間）→ 深く沈む（0.24 秒）→ 後ろなら跳ねて向き直る（0.36 秒）→ 弧を描いて駆け寄る（1.85m/s、歩きと走りのブレンド）→ 急に止まる → 体が前へ振れて戻る → 首をかしげ、手を一度引いてから素早く突き出す |
| 喜び（`cheer()`）  | 触れたものに応えがあったとき：沈む → 2回跳ねる（腕が上がる、笑顔、尻尾が立って振れる）→ 立ち姿に戻る。歩いている途中には割り込まない                                                                                                  |

間の長さ（気づく・沈む・整える・触れている）は、毎回 0.8〜1.25 倍に変わる。決まった数列（seed と回数）から取るので、同じ seed なら必ず同じに再生される。まばたき・見回し・耳の動きの時刻も同じ仕組み。

### 12原則の当てはめ（`living-body.ts`）

| 原則         | したこと                                                                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 予備動作     | 動き出す前に沈む（腰を下げ、体を縮め、前へ丸める）。手は出す前に一度引く。跳ねる前に沈む                                                       |
| 圧縮と伸長   | 1つのばね：沈み込み・急停止・着地で縮み（高さ −3.5%、幅が増える）、離すと行き過ぎて伸びてから戻る                                              |
| 余韻と時間差 | 体の傾きをばねにした（止まると前へ振れてから戻る）。胸と頭は遅れて付いてくる。目 → 頭 → 胸の順に向く。耳・尻尾・髪は揺れものが自分の時間で追う |
| 弧           | 興味は向きを変えながら走り出す（`turnFirst` を広げた）。手は直線ではなく、上に膨らんで目標へ下りる                                             |
| 緩急         | 興味は 0.25 秒で最高速、止まるのも同じくらい急。普段はゆっくり。跳ねて向き直る回転は、空中の真ん中で一番速い                                   |
| 誇張         | 手は目標を少し行き過ぎて押し込んでから戻る（興味は大きく）。首をかしげる。喜びの腕と尻尾                                                       |
| タイミング   | 気分ごとの間の長さ（上の表）と、その揺らぎ                                                                                                     |

そのほか：

- **走り**：`Jog_Fwd_Loop` を足した。歩きの速さを超えた分だけ混ぜ、位相は歩きと共有（歩幅は重みで混ぜる）ので、速くても足が床の速さに合う。2本の動作が逆の足から始まる場合は、読み込み時に半周期ずらす
- **耳と尻尾**：揺れもの（VRM の spring bone）にかかる力の向きを変えて演じさせる。耳は上向き（気づいた瞬間・興味・喜び・ときどきの動き）、尻尾は上向きと左右の振り。骨の名前に `ear`・`tail` を含むものが対象
- **表情**：まばたき、気づいたときの驚き（弱め）、喜びの笑顔（VRM の表情）
- **待機**：腕を内側へ 11°、ひじを 17° 曲げる。腰と肩を逆向きに傾けて体重を移す

### 柔らかいベッド（`src/living-room/soft-surface.ts`）

Blender の部屋には、布団の折り目・キルトの膨らみ・枕の膨らみがすでに作ってある（`scripts/living-room/30_bed.py`）。**部屋のファイル（`room.glb`・ライトマップ）は変えていない**。ブラウザーで足した：

- 座った所の布団・シーツ・毛布の頂点を、なめらかな山の形で押し下げる（深さ 7.5cm、半径 42cm、周りは少し盛り上がる）。焼いた光は頂点の色なので、へこみを少し暗くして見えるようにした
- 深さは1つのばね：沈むときは速く、行き過ぎる（腰を下ろした瞬間に押し込む）。戻るときはゆっくりで行き過ぎない（立った直後はへこみが残り、数秒で戻る）
- 体はへこみに乗る（腰の位置を沈んだ分だけ下げる）。腰は面の少し上に置く（前は寝具に埋まっていた）
- 頂点を書くのは面が動いている間だけ。布のシミュレーションはしていない
- していないこと：しわを増やす造形の変更（焼き直しが要る）、飛び乗る行動（座る直前の押し込みだけ）
