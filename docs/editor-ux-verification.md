# エディターUIの使い方と検証

対象は `codex/creator-editor-spike`、起点 `3569568`。UI実装は `fd5de3d`。2026-10-18に検証した。

## 操作

1. テーマをONにして、クリエイターエディターを開く。
2. 「画像を追加」「アニメーションを追加」、またはファイルのドロップで素材を置く。パネルへドロップした素材は見えるプレビュー側へ配置する。
3. レイヤー行のチェックを入れて複数選択。「すべて選択」も使える。Ctrl／Shiftクリックは従来どおり。
4. 選択数の下の「選択をグループ化」を押す。使えないときは同じ場所に理由が表示される。
5. 「光とマスクを設定」で基本変形を折りたたんでマスクを表示し、円形マスクを有効にする。「振る舞い」でマウス追従や動画の一時停止との連動を設定する。
6. 固定された「保存」で確定する。「未保存の変更」「保存済み」「保存失敗」が上部に表示される。破棄とUndo/Redoも従来どおり使える。

レイヤーの名前はダブルクリック、またはプロパティで変更できる。右クリックと各行の「…」から、複製・削除・グループ操作へ進める。長い名前は省略し、ホバーすると全文を表示する。

通常は幅360pxのパネルで一覧とプロパティを切り替える。「並べる」で同時表示、「パネルを左へ／右へ」で左右移動、内側の縁をドラッグして幅を調整できる。幅調整にはフォーカス後の左右キーも使える。「−」でプレビューを広げ、「＋」で戻す。740px以下では同時表示を避ける。

ガイドを閉じた状態だけ拡張のローカルストレージに保存する。「使い方」から再表示できる。幅や左右配置は編集セッション内で保持する。

## 変更した責務

| モジュール | 内容 |
| --- | --- |
| `editor/layer-tree.ts` | チェック選択、階層、サムネイルキャッシュ、名前変更、表示・ロック、並び替え |
| `editor/workspace.ts` | 作業領域、折りたたみ、幅、メニュー、ガイド、選択数とフィードバック |
| `editor/panel.ts` | 対象別プロパティと既存の編集アクションとの接続 |
| `editor/effects-panel.ts` | 光とマスク、振る舞いを分けた設定。保存するbindingsは従来と同じ |
| `renderers/dom/thumbnail.ts` | 表示済みの画像・canvas・videoから96×72の静止プレビューを取得。Lottieは検証済みRendererの静止SVGを使用 |

複製はasset IDを共有する。サムネイルは素材ごとに共有し、別の動画再生器やアニメーションのデコーダーを起動しない。パネルが閉じたり非表示になった場合は取得を止める。終了後の非同期結果は反映しない。

World Runtime、DesignDocument v7と移行、IndexedDB、Chrome権限、依存パッケージは変更していない。`main` と通常版 `dist` も変更していない。

## 制約と次の改善

- グループは同じアンカー、連続した重なり順の最上位素材に限る。多重ネスト・グループの拡縮と回転は既存の制約を維持する。
- グループ解除では共通マスクが外れる。不透明度を100%に戻す必要がある。どちらもUIに案内する。
- 自由なパネルの分離・ドッキング、素材ライブラリー、タイムラインは今回は追加していない。
- 未描画・非表示などでサムネイルを取得できない素材は種類アイコンで表示する。アニメーションのサムネイルは動かさない。
- 次は初心者による操作観察と、実サイトの画面モードを変える回帰確認を優先する。

実験版を読み込むフォルダーは、この専用worktreeの `dist/`。通常版のルート `dist/` を上書きしない。
