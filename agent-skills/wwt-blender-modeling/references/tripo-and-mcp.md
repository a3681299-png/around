# Tripo と Blender MCP（2026-11-08、自分の判断で使ってよい）

## いつ使うか

- **Tripo**：手で作ると時間がかかる、有機的な形や凝った形の下書き（船の船体、木、文化の建物の飾り、楽器、屋台の品など）。生成したら必ず WWT の絵柄に直す
- **Blender MCP**：Blender を開いた状態で、形を見ながら直したいとき（面の分け方、面取り、シルエットの調整）。直した手順は最後にスクリプトに落とす
- **使わない方がいい物**：単純な箱や板（スクリプトで作る方が速くてきれい）、住人の体（素体を使う）、つむ（配布物を使う）

## Tripo の決まり

- 送ってよいのは、文章の指示と、自分で作った絵や形だけ。つむ・素体・他人の作品・実在のブランドの画像やモデルは送らない
- 指示に、実在の作品・キャラクター・ブランドの名前を入れない
- 生成物の権利と公開の条件は、使っているプランで変わる。使う前に、今のプランの利用条件（商用・公開・クレジット）を確かめ、manifest の `source` に、プラン・生成日・タスク ID・指示の要約を書く。条件が分からない物は公開に載せない
- API キーは環境変数で渡し、リポジトリやログに残さない
- クレジットの使いすぎに気をつける。1つの素材に試すのは数回までにし、合わない物はスクリプトで作る方に切り替える

## 生成物を直す手順（必ず通す）

1. 元の生成物は wwt-private-assets の city-assets/tripo/ に置く（直す前のまま）
2. 大きさを実寸と WWT のデフォルメ比率に、向きと原点を約束どおりに
3. 面を減らす（三角形の上限）。細かい凹凸は消し、平らな面にする
4. テクスチャを外し、材質を約束の部位の名前（slot_*）に分けて付け直す。色は世界が色の表から当てる
5. 面取りを1段にそろえ、閉じた形にし、法線を外向きにそろえる
6. 直す手順をスクリプトにする（元の生成物を読み込んで、同じ GLB が出る）
7. 検査（`wwt-asset-contract`）と並べて撮る（`wwt-asset-review-loop`）

## Blender MCP の決まり

- 触るのは作業用の .blend だけ。元のファイル（素体・つむ・Tripo の元）は上書きしない
- MCP で直したら、その手順をスクリプトに書き直してから書き出す（同じ物を作り直せるように）
