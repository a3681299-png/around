# 小物・船・港・街・文化の建物

## 手の小物（三角形 500 まで）

荷の箱、ランタン（`slot_light` の火）、ほうき、紙袋、点火棒、楽器（架空の形のギター・小さな太鼓）、望遠鏡、じょうろ、皿、釣り竿。原点は握る所。少し大きめ。

## 船（3,000 まで）

- ずんぐりした小さな貨物船と、帆のある小舟の2種類から
- 甲板に荷の山（荷の箱を並べる）。窓は `slot_light`
- 原点は水面の高さの中心。前は +Z

## 港の物

桟橋（板の段）、係船柱、荷の山、クレーン（太い部材で）、倉庫の扉。桟橋は道とつながる高さにする。

## 街の物（800 まで）

街灯（灯りは `slot_light`）、ベンチ、木（丸い葉の塊を2〜3段）、植え込み、標識（架空の文字の板）、ポスト、自転車（太めにデフォルメ）。

## 文化の建物（6,000 まで）

| 文化 | 建物             | 見どころ                                   |
| ---- | ---------------- | ------------------------------------------ |
| 音楽 | 屋外の小さな舞台 | 屋根、照明（`slot_light`）、客席のベンチ   |
| 天文 | 観測台           | ドーム、望遠鏡の筒、夜に窓が灯る           |
| 自然 | 庭               | 花壇、温室（`slot_glass`）、じょうろ置き   |
| 食   | 屋台             | のれん（架空の文字）、提灯（`slot_light`） |
| 海   | 漁師小屋         | 網、浮き、干した魚の形                     |

## CC0 の素材を絵柄に合わせる

- Kenney・Quaternius などの CC0。使う前に付いているライセンスの文を確かめ、出どころを記録する
- 材質を約束の部位の名前に付け直す（テクスチャを外して部位の色にする）
- 細かすぎる所は消し、太らせる。面取りを1段にそろえる
- 大きさを実寸と WWT のデフォルメ比率に合わせる
