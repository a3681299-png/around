# WWT Blender Modeling

遠くからは街の一部、近づくと生活が見える。そのための形は、細かさより「シルエットが読めること」と「平たい色の面がきれいに分かれていること」。

## Core rule

形はスクリプトで作る。Tripo や Blender MCP で作った・触った形も、最後はスクリプト（元の生成物を読み込んで直す手順）から作り直せる状態にする。1つの形を作り込むより、組み合わせで数を増やす。

## 形の決まり（トゥーンと輪郭線で映えるように）

- **ALWAYS** シルエットを大きく分かりやすく。帽子・手の小物・体型で、遠くからでも役割が分かる
- **ALWAYS** デフォルメの比率に合わせる（つむと住人の頭身をそろえる。小物は少し大きめ、太めに作る）
- **ALWAYS** 面は平らに、色の境目を形の境目に合わせる（材質の部位ごとに面を分ける）。細かい凹凸は作らない
- **ALWAYS** 角は少しだけ面取り（1段）して、輪郭線と光の段がきれいに出るようにする
- **ALWAYS** 厚みのある閉じた形にする（裏返した輪郭線のため）。紙のような1枚の面は避ける
- **NEVER** 顔を作り込まない（住人には顔の造形も表情もいらない。つむだけが顔を持つ）
- **NEVER** 細い線の物（電線・細い手すり）を形で作らない。遠くで点滅する
- **NEVER** 実在のブランドの形やロゴを作らない。看板の文字は架空

## スクリプトの書き方

- Blender をバックグラウンドで動かすスクリプト（`blender -b -P make_xxx.py -- --out ...`）。入力の元ファイルと出力先を引数で受ける
- ノート PC の Blender は `C:/Program Files/Blender Foundation/Blender 5.2/blender.exe`（5.2.2 LTS、`-b --factory-startup` で動く）。スクリプトは wwt-private-assets の `city-assets/tools/`、まとめて作り直すのは `city-assets/tools/build_all.py`
- 1つの素材に1つの作る関数。材質は約束の部位の名前で作り、色は仮の灰色の段（色は世界が当てる）
- 形の数値（帽子のつばの幅、箱の大きさなど）は関数の先頭か設定ファイルにまとめ、見て直しやすくする
- 作ったら約束の検査（`wwt-asset-contract`）を回し、並べて撮る（`wwt-asset-review-loop`）

## 手順

1. 元の素体・CC0 の元を wwt-private-assets に置き、出どころを記録する
2. 作るスクリプトを書く（住人は residents.md、物は props-and-places.md）
3. 書き出して検査する
4. 並べて撮って採点し、弱い所を3つ直す
5. 一覧を更新してコミット・push

## Report

作ったスクリプトの場所、作った物、検査の結果、ラインナップの絵、使った CC0 の出どころ。
