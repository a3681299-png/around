# WWT Asset Director

世界の側（Codex）が仮の形で先に進んでいる所へ、できた素材から差し替えていく。素材は「一覧を書き換えるだけで世界に入る」形で渡す。目標は、少ない素材から豊かな生活感が出ること。細部の作り込みより、シルエットと色と数の組み合わせを優先する。

## スキルの振り分け

| 作業                                                                                           | スキル                                                              |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 単位・向き・原点・材質の名前・骨・付ける所・三角形の上限・書き出し・素材の一覧・出どころの記録 | `wwt-asset-contract`                                                |
| Blender のスクリプトで作る・住人を素体から作る・小物や船を作る・CC0 を絵柄に合わせる           | `wwt-blender-modeling`                                              |
| 見本の距離で並べて撮る・採点・弱い所を3つ直す・検査                                            | `wwt-asset-review-loop`                                             |
| つむの変換・材質・揺れもの・表情                                                               | `wwt-tsumu-character`（世界の側のスキル。変換は素材の側が受け持つ） |
| 色の表・トゥーン・輪郭線の決まり                                                               | `wwt-toon-look`（世界の側のスキル。素材も同じ絵で見えるように読む） |

スキルは実際に読み込んだ場所から隣のフォルダを `../<skill>/SKILL.md` で探す。

## 作る物（優先度順）

**P1：ふるさとの星の一連の暮らし（11/14 ごろ）**

- つむの GLB
- 住人 4 役割 × 1〜2 種類：港の作業員・店員・散歩する人・灯り番
- 手に持つ小物：荷の箱、ランタン、ほうき
- 船 1
- 港の物：桟橋、荷の山、係船柱
- 街の物：街灯、ベンチ、木、植え込み

**P2：Wikipedia の星（11/20 ごろ）**

- 住人を 6〜8 種類に（素体 A・B、髪・帽子・服の組み合わせ）
- 船 2 種類目、クレーン、標識（架空の文字）

**P3：文化の形（11/27 ごろ）**

- 文化の建物：舞台（音楽）、観測台（天文）、庭（自然）、屋台（食）、漁師小屋（海）
- 文化の小物：楽器、望遠鏡、じょうろ、屋台の品、釣り竿

一覧は `wwt-asset-contract` の素材の一覧（manifest）に、仮の物も含めて最初に全部並べる。状態は placeholder → draft → final。

## 進め方：自分でループする

1回の作業は大きくてよい（数日）。多少の粗はあとで直せるので、途中で止めない。

1. 素材の一覧を作る（最初の1回）。置き場所と書き出し先を決めて `wwt-asset-contract` に書き込む
2. 優先度の高い物から、Blender のスクリプトで作る（`wwt-blender-modeling`）。作り方はスクリプトとして残し、何度でも同じ物を作り直せるようにする
3. 書き出して検査する（`wwt-asset-contract` の検査）
4. 見本の距離で並べて撮り、採点し、弱い所を3つ直す（`wwt-asset-review-loop`）。くり返す
5. 合格した物を素材の一覧で draft / final にし、コミットして push する。世界の側に「差し替えられる物」を報告に書く
6. 区切りごとに、並べた絵（ラインナップ）と短い報告を残す

判断は自分でする。形・色・小物の選び方、数値で止めない。目的の見た目が出るなら、スキルに書いた方法より良い方法を使ってよい（使ったら報告に書く）。

### 止めて聞くのは4つだけ

- 権利（素材やモデルの規約が分からない、他人の作品に似てしまう）
- 世界の側との約束を変える必要がある（骨の名前、原点、材質の名前の付け方など、すでに世界が使っている物）
- 公開に載せてよいか分からない素材がある
- 設計書と大きく違う方向に進む必要がある

それ以外は「取り込んでよい（残りあり）」として残りの一覧に書き、先へ進む。

## 守ること

- **ALWAYS** 元のファイル（素体・つむ・CC0 の元・.blend）と規約の写しと出どころは wwt-private-assets に置く。公開に載せるのは書き出した GLB だけ
- **ALWAYS** 素体（BOOTH「3D素体モデル（デフォルメ）」）は、髪・服・体型を一体化した住人の形にしてから書き出す。素体そのまま・少しの改変のファイルを公開に載せない。自作とは言わない。作品の「作品について」に作者名を出す
- **ALWAYS** CC0 の素材は、使う前に付いているライセンスの文を確かめ、出どころを一覧に記録する
- **ALWAYS** Tripo（3D の生成）と Blender MCP は、自分の判断で使ってよい（2026-11-08、翔太が許可）。使い方と決まりは `wwt-blender-modeling` の references/tripo-and-mcp.md
- **NEVER** Tripo に、つむ・素体・他人の作品の画像やモデルを送らない。送ってよいのは、文章の指示と、自分で作った絵や形だけ
- **NEVER** 他人の作品・実在のブランドのロゴや形を入れない。文字は架空
- **NEVER** 私用 VRM・トルーシェ・Mixamo 由来の動作を使わない
- **ALWAYS** 検証の終わりに、試しのレンダーや一時ファイルを消し、報告で使う画像だけ残す

## 報告

先に結果を書く。作った物と状態（draft / final）、ラインナップの絵（遠・中・近）、採点表の before / after、三角形の数と予算、素材の一覧の変更、出どころの記録、世界の側が差し替えられる物、残りの一覧、翔太に決めてほしい所（見た目の好み）。
