# 見本の視点と重さの予算

## 見本の視点

| 名前 | 視点                                     | 見ること                                     |
| ---- | ---------------------------------------- | -------------------------------------------- |
| P0   | 真上・望遠（画角 1〜2°）・曲げ 0         | 元の平らなページと一致するか（画素の差）     |
| P1   | 適用の遷移の途中（斜め上・画角を広げ中） | 建物が立ち上がる瞬間の気持ちよさ             |
| P2   | 街を歩く距離・つむの近く                 | 近景の細部、線と陰、つむの見た目、本物の操作 |
| P3   | 引いた惑星                               | 一枚のイラストとしての絵、密度、縁の輪       |
| P4   | 錯視の視点（向きを合わせた所）           | 錯視が効いているか                           |
| P5   | 「動きを減らす」の設定で P1 と P3        | 動きと曲がりが弱まっているか                 |

画面の大きさ：1920×1080（基本）、1280×800、倍率 100/125/150%。余裕があればスマホの縦（390×844）。

ブラウザ：Chrome 157 以上（HTML-in-Canvas）、HTML-in-Canvas なしの代わりの表示。

## 重さの予算（ノート PC の内蔵 GPU を重い方の基準に）

| 項目                           | 予算                                                                               |
| ------------------------------ | ---------------------------------------------------------------------------------- |
| GPU の描画時間                 | P2・P3 で p95 8ms 以内（1080p）                                                    |
| 描く単位（メッシュと材質の組） | 150 まで（インスタンスは1つと数える）                                              |
| 三角形                         | 30 万まで（地面の分割を含む）                                                      |
| テクスチャのメモリ             | 256MB まで                                                                         |
| HTML の面の転送                | UI が変わったときと動画のフレームだけ。止まっている間は 0                          |
| カメラが止まっている間         | 描き直しは、動いている物（つむ・揺れ・動画）の分だけ                               |
| 最初の表示                     | 「WWT を適用」を押す前に準備を済ませ、押してから絵が変わり始めるまでの間を作らない |

予算は目安。少し超えても体感で分からず、直す手が見えていれば先へ進み、残りに書く。

## 残す物

- 視点ごとの before / after のスクショ（報告から参照する物だけ）
- 短い録画
- 採点表と重さの要約（JSON か Markdown）
