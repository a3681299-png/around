# 並べるページと採点表

## 並べるページ

- web-world-themes の中に、開発用の小さなページを1つ作る（製品のビルドには入れない）。three.js で、素材の一覧（manifest）を読み、全部を地面の上に一列に並べる
- 描き方は世界と同じトゥーン・輪郭線・色の表。世界の側の材質の工場があればそれを使い、なければ同じ決まりで簡単に作る（世界の側ができたら差し替える）
- 決まった時間・カメラ・種で撮れる入口を付け、Playwright で撮る
- 置き場所（2026-11-08）：`scripts/city-assets/lineup/`。撮るのは `node scripts/city-assets/capture-lineup.mjs <出力のフォルダ>`（esbuild で `.work/city-lineup/` に組み、画面の外の表示ありの Chromium で撮る）。残す絵は `docs/screenshots/city-assets/<区切り>/`
- 動作は付けなくてよい。住人は立ち姿と、手の小物を付けた姿の2つ

## 見本の距離

| 名前    | 距離                                | 見ること                                            |
| ------- | ----------------------------------- | --------------------------------------------------- |
| L-far   | 惑星の視点で、住人が画面で 12〜20px | 役割が読めるか、街に馴染むか、点滅しないか          |
| L-mid   | 街を見下ろす距離、住人が 60〜90px   | 帽子・小物・服の色の組み合わせが効いているか        |
| L-near  | つむの目の高さ、住人が 300px 前後   | 形のきれいさ、輪郭線、面取り、手の小物の収まり      |
| L-sil   | L-mid を黒一色の影絵で              | 役割ごとにシルエットが違うか                        |
| L-night | L-mid を夜の色で                    | `slot_light` が効いているか、住人の縁が光で読めるか |

## 採点表（0〜3）

| 項目                | 見ること                             |
| ------------------- | ------------------------------------ |
| 1. 遠くで読める     | 役割が影絵と遠景で分かる             |
| 2. 街に馴染む       | 色・線・比率が街とつむにそろっている |
| 3. 数の豊かさ       | 20 人並べても同じ人に見えない        |
| 4. 近くで気持ちいい | 形・面取り・線がきれい。素の箱がない |
| 5. 小物の説得力     | 握っている・運んでいるように見える   |
| 6. 夜               | 灯りが効いていて、夜の街が魅力的     |
| 7. 軽さ             | 三角形・材質の数が予算内             |
| 8. 約束             | 検査がすべて通る                     |

合格の目安：全項目 2 以上、1・2・3 は 3。
