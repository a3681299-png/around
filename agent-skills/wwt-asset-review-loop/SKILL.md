# WWT Asset Review Loop

Blender の中できれいでも、星の上で小さく見えたときに読めなければ意味がない。世界と同じ描き方、同じ距離で見て直す。

## References

| File                                 | Read it when                     |
| ------------------------------------ | -------------------------------- |
| `references/lineup-and-scorecard.md` | 並べるページ、見本の距離、採点表 |

## Core rule

素材の良し悪しは、世界と同じ絵で、世界と同じ距離で決める。Blender の見た目では決めない。

## ループ

1. 並べるページ（lineup-and-scorecard.md）で、今の素材を遠・中・近と影絵で撮る。つむを高さの基準として必ず並べる
2. 採点表で採点する（各項目に1行の根拠）
3. 弱い所を3つ、名前を付けて挙げる（例：「港の作業員と店員が遠くで同じに見える」）
4. 直す（スクリプトの数値か形）
5. もう一度撮る。下がった項目がないかも見る
6. 合格した物を一覧で draft / final にする

## 決まり

- **ALWAYS** 世界の色の表（`wwt-toon-look`）で色を当てて撮る。灰色のままで合否を決めない
- **ALWAYS** 撮る条件（カメラ・光・時間帯・色の組み合わせ）を決めて、また同じ絵が撮れるようにする
- **ALWAYS** 昼と夜（`slot_light` が光る）の両方で撮る
- **NEVER** 同じことを何通りも撮り直さない。区切りごとに1回
- **ALWAYS** 試しのレンダーや一時ファイルは消し、報告で使う絵だけ残す

## Report

ラインナップの before / after（遠・中・近・影絵・夜）、採点表、直した弱い所、残りの一覧。
