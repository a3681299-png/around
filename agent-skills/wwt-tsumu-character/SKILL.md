# WWT Tsumu Character

つむは街の住人。見ている人には法則がおかしく見える街でも、つむにとってはふつうの毎日。

## References

| File                            | Read it when                                           |
| ------------------------------- | ------------------------------------------------------ |
| `references/import-pipeline.md` | FBX からの変換、骨・表情・揺れもの・材質・動作の当て方 |

## Core rule

つむの動きはすべて平らな街の座標で決める（`wwt-world-bend`）。描くときだけ街と一緒に曲がる。見た目は街と同じトゥーンと輪郭線（`wwt-toon-look`）で、街から浮かない。

## 決まり

- **ALWAYS** 元のファイル（FBX・unitypackage・PNG）は wwt-private-assets に置き、規約の文の写しと出どころ（URL・版・取得日）を一緒に記録する
- **ALWAYS** Playground に載せるのは、変換した GLB と必要なテクスチャだけ。規約の範囲で使う。クレジットが要るなら Playground の「作品について」に出す
- **ALWAYS** 姿を出すのは、動作を骨に反映してからにする（T ポーズを見せない）
- **ALWAYS** 足は地面に接地させ、すべらせない。座るときは座る所に合わせてから座る
- **NEVER** 口の形がないので、口を動かそうとしない。気持ちは目・眉・体の動き・間で出す
- **NEVER** 私用 VRM・トルーシェ・Mixamo 由来の動作を使わない
- **NEVER** つむに本物の UI の操作部品を隠させない（近い視点で板の前を横切らない）

## 暮らし方（出発点）

街の物の「できること」（`wwt-page-to-city` の対応表）から、今の気持ちと周りの変化で行動を選ぶ。今ある自律の仕組み（状態機械・Utility AI。docs/autonomy-plan.md）を使う。

| きっかけ                       | つむの反応の例                                 |
| ------------------------------ | ---------------------------------------------- |
| 動画が再生中                   | 湖のほとりに座って見る、拍に合わせて体が揺れる |
| 動画が止まる                   | 振り向いて、カメラ（見ている人）を見る         |
| 新しいコメントで道が伸びる     | 伸びた先へ歩いて見に行く                       |
| カードの建物                   | 看板を覗き込む、屋根の縁に座る                 |
| 見る人が急に引く（惑星になる） | 一瞬空を見上げる。気づくだけで、驚きすぎない   |
| 錯視の道がつながる             | 見かけの道を渡る                               |
| しばらく何もない               | 寄り道、ベンチで休む、眠そうにする             |

遠い所へは歩き、急ぐときは小走り。とても遠い所は消えて現れてよい。座ったまま宙を滑らない。

## 手順

1. import-pipeline.md の手順で GLB を作り、骨・表情・揺れものを確かめる
2. 材質を街のトゥーン＋輪郭線にする
3. CC0 の動作（Quaternius）を、今ある「当てて・直して・試す」の仕組みで当てる。崩れた動作は外す
4. 街での暮らし方をつなぐ
5. `wwt-visual-loop` で撮って、つむの項目を採点する

## Report

変換の手順と使った道具、骨の対応表、使える動作と外した動作、表情の対応、つむの暮らしの録画、規約の記録の場所。
