# WWT World Bend

平らな世界を、見る位置によって姿を変える世界にする。地面は平らなまま、描くときだけ曲げる。

## References

| File                      | Read it when                                                     |
| ------------------------- | ---------------------------------------------------------------- |
| `references/bend-math.md` | 曲げの式・法線・輪郭線・影・選び（クリック判定）を実装・直すとき |
| `references/illusions.md` | 錯視・不可能建築・つながる世界を作るとき                         |

## Core rule

曲がりは「位置を変える」のではなく「見え方を変える」。物理・経路・配置・クリックの意味は、すべて平らな座標で決める。曲げるのは描く段だけ。

## 決まり

- **ALWAYS** 曲げは1つのモジュールに置き、全部の材質（建物・地面・小物・つむ・輪郭線・影の深さ・UI の板・選び用の描画）が同じ関数と同じ uniform を使う。1つでも外れると、継ぎ目がずれる
- **ALWAYS** 曲げの強さはカメラの状態から決める。近い（街を歩く距離）＝ほぼ平ら、遠い＝惑星。間はなめらかにつなぐ（距離は対数でつなぐ）
- **ALWAYS** 平らで大きい面（地面・道・湖・大きな屋根）は細かく分割する。目安：曲がりが最大のとき、1辺が画面で 16px を超えて直線に見えない細かさ
- **ALWAYS** 真上の見本の視点（P0）では曲げ 0、望遠（画角 1〜2°）で、元のページと画素がほぼ一致すること。ここから画角を広げながら寄る（ドリーズーム）ので、平行投影と透視投影を途中で切り替えない（切り替えると跳ぶ）
- **ALWAYS** 曲げの中心はカメラの注目点（地面の上）。注目点が動いても、注目点の真下は常に平ら
- **NEVER** 物理・経路・つむの足の接地を、曲げたあとの座標で計算しない
- **NEVER** ページの外側（世界の端）を、惑星の裏側まで曲げて見せない。曲げの角度が約150°を超える所は空に溶かすか、世界をつなげて（illusions.md）裏側に意味を持たせる

## カメラ操作（見る人）

- ホイール・ピンチ：近づく／離れる。離れるほど曲がりが強くなる
- ドラッグ：星を回す（注目点を地面の上で動かし、向きを回す）。慣性は短く
- 建物や物を押す：そこへカメラが飛ぶ（ゆっくり始まりゆっくり止まる。画角と距離は対数でつなぐ）。押した物が本物の UI の部品で、近い視点なら、カメラは動かさず UI の操作として届ける（`wwt-page-to-city` の G1）
- 「動きを減らす」：飛ぶ動きは短い溶け合わせ（クロスフェード）に置き換える。慣性なし
- カメラは傾けすぎない。地平線が画面の外へ大きく回り込む向きは使わない（酔いを避ける）

## 実装の手順

1. 今の描画器（WebGLRenderer か WebGPURenderer か）を確かめ、その流儀で曲げを差し込む。WebGL は `onBeforeCompile` で `project_vertex` の前後を差し替える。WebGPU は TSL のノードで同じ式を書く。式は bend-math.md
2. 影の深さの材質・選び用の材質にも同じ曲げを入れる
3. 地面の分割を足す
4. 見本の視点 P0〜P4 を作り、`wwt-visual-loop` で撮る
5. 選び（どの物か・平らな地面のどこか）を同じ曲げで描いた画像から読む
6. カメラ操作を入れる
7. 錯視を足す（数は2〜3個に絞る）

## Report

曲げの実装場所、使った方式、見本の視点ごとのスクショ、P0 と元のページの差（画素の差の割合）、選びの正しさの確かめ方、カメラ操作の録画、重さ。
