# 錯視と不可能建築

数は2〜3個に絞る。1つずつ「見る人が自分の操作で気づける」ようにする。見せ場の採点（wwt-visual-loop）で効いていない物は外す。

## 1. 平らなページ ＝ 街（必須）

真上の望遠では、屋根に貼ったカードの面が元のページそのものに見える。カメラが傾くと、建物の壁が現れ、立ち上がる。ページと街は同じ物を別の視点から見ただけ、と分かる。これが最初の見せ場。

## 2. つながる世界（候補）

ページの左右（または上下）をつなぎ、端を越えると反対側から出てくる。引いた惑星の視点では、つむが星を一周して元の場所に戻るのが見える。平らな座標では「端で反対側へ移る」だけで、経路も簡単。

## 3. 見る向きで道がつながる（候補）

2つの離れた足場が、ある視点から見たときだけ画面の上でつながって見える。見る人が星を回して向きを合わせると、つむがその「見かけの道」を渡れる（Monument Valley に近い考え方。絵や形は写さない）。

実装の目安：渡れる候補の2点を決め、今のカメラで2点の画面上の位置が数 px 以内に重なっている間だけ、経路に一時的なつながりを足す。渡っている間は、つむの描く位置を見かけの道に合わせる。

## 4. 下にいるのに落ちない（曲がりで自然に出る）

惑星の視点では、星の下側の建物やつむが逆さに見えるのに、本人たちはふつうに暮らしている。曲げだけで自然に出るので、つむが下側にいる時間を作るだけでよい。

## 守ること

- 錯視の間も G1 と文字の決まりは同じ
- 強い錯視は「動きを減らす」では弱めるか、止まった絵で見せる
