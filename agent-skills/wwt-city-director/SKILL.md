# WWT City Director

Playground を「触った瞬間に驚き、探索すること自体に意味がある Web の街」に仕上げる。審査員が自分の手で、平らなページが街になり、引くと惑星になり、つむがそこで暮らしているのを確かめられる状態がゴール。

## 世界の約束（変えない）

- 地形と物は平らなまま持つ。丸く見えるのは描くときの投影だけ。つむの歩く・座る・経路は平らな地面で計算する
- 真上から望遠（平行投影に近い）で見た街は、元の平らな動画サイトと同じに見える。「WWT を適用」でカメラが傾き、カードが建物として立ち上がるのが最初の見せ場
- 近づくと曲がりが弱まり、ふつうの街になる。引くと小さな惑星になる
- つむにとってはふつうの街。見ている人間にだけ、物理の法則がおかしく見える
- 緩めない線は4つ：操作を壊さない（G1）、文字が読める（読む距離で 4.5:1 以上）、作品データの安全（JS・任意の CSS・シェーダー・セレクターを入れない。曲がりや錯視はエンジンの決まった効果で、作品は数値だけ持つ）、権利（私用 VRM・トルーシェ・Mixamo 由来の動作・他人の作品の絵やロゴを入れない。素材は CC0 か自作か規約で許された物）

## スキルの振り分け

| 作業                                                                 | スキル                |
| -------------------------------------------------------------------- | --------------------- |
| 曲がり・惑星・真上の姿から街への遷移・カメラ操作・クリック判定・錯視 | `wwt-world-bend`      |
| トゥーン・輪郭線・色・空・ローポリの小物・採点表                     | `wwt-toon-look`       |
| ページの部品から街を作る・屋根のカード・HTML-in-Canvas・G1           | `wwt-page-to-city`    |
| つむの取り込み・材質・揺れもの・表情・動作・自律                     | `wwt-tsumu-character` |
| 静止画の見本・採点・弱い所を直すループ・重さ                         | `wwt-visual-loop`     |

スキルは実際に読み込んだ場所から隣のフォルダを `../<skill>/SKILL.md` で探す。

## 進め方：自分でループする

1回の作業は大きくてよい（数日）。多少の粗はあとで直せるので、途中で止めない。

1. 今の Playground を `wwt-visual-loop` の見本の視点で撮り、採点する（初回は「before」として残す）
2. いちばん効く所から作る。順番の目安：平らなページと真上の姿が一致する → 適用で街が立ち上がる → 引くと惑星 → つむが街で暮らす → 絵の密度と仕上げ → 錯視
3. 区切りごとに見本の視点で撮り直し、採点し、弱い所を3つ挙げて直す。これをくり返す
4. 区切りごとにコミットして push し、録画とスクショを残す（翔太がいつでも覗けるように）
5. 採点表の全項目が 2 以上、見せ場の項目が 3 になるか、本当に詰まったらそこで報告する

判断は自分でする。細かい実装の選び方、数値、素材の配置で止めない。目的の見た目と体験が出るなら、このスキルに書いた方法より良い方法を使ってよい（使ったら報告に書く）。

### 止めて聞くのは4つだけ

- G1 を、守りを弱めずに満たせない
- 権利（素材やモデルの規約が分からない、他人の作品に似てしまう）
- Chrome の権限を増やす必要がある
- 設計書と大きく違う方向に進む必要がある

それ以外は「取り込んでよい（残りあり）」として残りの一覧に書き、先へ進む。

## 守ること

- **ALWAYS** 作品データの版上げは必要なときだけ、移行は1段ずつ
- **ALWAYS** 「動きを減らす」（prefers-reduced-motion）では大きなカメラの動きと強い曲がりを弱める。光の明滅は1秒3回まで
- **ALWAYS** 見る人が動かしたときだけカメラが大きく動く。自動で大きく動かさない
- **NEVER** 参考の絵（明るい小さな惑星の街）を写さない。技法だけ借り、絵は WWT 独自にする
- **NEVER** 外部の生成 API に素材を送らない
- **ALWAYS** 検証の終わりに、試行ごとのブラウザのプロファイルとビルドを消し、要約と報告で使う画像・録画だけ残す

## 報告

先に結果を書く。採点表の before / after（各項目1行の根拠つき）、見本の視点ごとのスクショと録画、直した所、重さの数字（`wwt-visual-loop` の予算と比べて）、変えたファイル、残りの一覧、翔太に決めてほしい所（見た目の好み）。試せなかったことは、試せなかったと書く。
