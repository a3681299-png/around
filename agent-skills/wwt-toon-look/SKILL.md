# WWT Toon Look

明るい、やさしい、でもぼんやりしない絵。遠くからは一枚のイラスト、近づくと手で触れそうな模型の街。

## References

| File                         | Read it when                               |
| ---------------------------- | ------------------------------------------ |
| `references/look-recipes.md` | 材質・陰・輪郭線・空・影・小物の作り方     |
| `references/scorecard.md`    | 見た目を採点する・「良くなった」と言うとき |

## Core rule

形 → 色の面 → 陰の段 → 輪郭線 → 空と光 → 小物の密度、の順に作る。光らせる効果やぼかしで、素の箱を良く見せようとしない。

## 決まり

- **ALWAYS** 色は決めた色の表（look-recipes.md）から取る。新しい色が要るときは表に足してから使う
- **ALWAYS** 陰は2〜3段の帯で塗る。なめらかなグラデーションの陰にしない
- **ALWAYS** 輪郭線は濃い紺（真っ黒にしない）。太さは画面の画素でそろえ、手前ほど少し太くする。曲げ（`wwt-world-bend`）と同じ曲がり方にする
- **ALWAYS** 素の箱を残さない。どの箱にも、縁・窓・看板・屋上の物・足元のどれかを足す
- **ALWAYS** 遠景（惑星の視点）で、画面の中に大きな何もない面を作らない。緑地・家並み・小物で埋める。ただし目を休める空は残す
- **NEVER** 参考の絵の配色や形をそのまま写さない
- **NEVER** 画面全体に線を引く重い後処理を常に回さない（部屋の測定で GPU 18ms だった）。使うなら軽い形だけ、重さの予算の中で
- **NEVER** 他人の作品・実在のブランドのロゴや絵を看板に入れない。文字は架空の名前

## 手順

1. 色の表と陰の段を決め、材質を1つの工場（関数）にまとめる
2. 地面・道・湖・建物の基本の形をローポリで作る（ページから作る形は `wwt-page-to-city`）
3. 輪郭線を足す
4. 空のグラデーション、柔らかい太陽、影
5. 小物を足して密度を上げる（CC0 か自作。同じ物はインスタンスで描く）
6. `wwt-visual-loop` で撮って採点し、弱い所3つを直す。くり返す

## Report

採点表の before / after、見本の視点ごとのスクショ、色の表の変更、使った素材と出どころ（ライセンス）、重さ。
