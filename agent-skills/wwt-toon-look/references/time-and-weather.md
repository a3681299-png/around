# 時間と天気（2026-11-08 決定）

## 時間：本物の時刻で変わる

- 見る人のパソコンの時刻（`Date`）だけで決める。許可も通信もいらない
- 時間帯は 朝・昼・夕・夜 の4つ。それぞれ色の表（空の上・空の地平・光の色・陰の色・全体の明るさ）を持ち、時刻で隣り合う2つを混ぜる
- 太陽と月の位置も時刻で動く。夕方から街灯と窓の明かりがつく。夜はプレーヤー（湖のスクリーン）の光が一番明るく、周りを照らす
- つむ：朝は伸び、昼は散歩、夜は眠そう、深夜はベンチでうとうと（自律の気持ちの重みを時間帯で少し変えるだけ）
- 夜も昼と同じくらい魅力的にする（審査員が夜に開くかもしれない）。夜の採点も見本の視点に入れる
- 色の表は作品データの数値。エンジンは決まった混ぜ方だけを持つ

## 天気：本物の天気は使わない

- 外の天気 API や位置情報は使わない
- 天気は動画が決める：動画ごとに天気（晴れ・曇り・雨・雨あがり・雪 など）を作品データの数値で持ち、その動画を開くと街の天気がゆっくり変わる。「動画が分かっている」を見せる演出
- 見せ方の例：雨は道が濡れて街灯が映る・水たまり・つむが傘をさす（傘は自作か CC0）、曇りは空が落ち着き影が薄い、雪は屋根と道が白くなる
- 順番：時間を先に入れる。天気は、街・つむ・惑星が一通り動いてから

## 見る人が遊べるように

- 手前の操作に「時間を回す」つまみと天気の切り替えを置く。「今の時刻に戻す」ボタンも付ける
- 操作は曲がらない手前の層に置き、G1 と文字の決まりを守る

## 守ること

- 光の明滅は1秒3回まで（雷など）
- 「動きを減らす」では雨・雪・時間の移り変わりの動きを弱める
