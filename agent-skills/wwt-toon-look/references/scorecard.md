# 採点表

各項目 0〜3。根拠を1行ずつ書く。0＝できていない、1＝ある、2＝ちゃんとしている、3＝見せ場として強い。

| 項目                  | 見ること                                                                       |
| --------------------- | ------------------------------------------------------------------------------ |
| 1. 平らから街への発見 | 真上の姿が元のページと一致し、傾くと建物が立ち上がるのが一目で分かるか         |
| 2. 惑星の一枚絵       | 引いた視点が、そのまま一枚のイラストとして飾れるか（構図・余白・密度）         |
| 3. 近景の探索         | 近づいたとき、歩いてみたくなる細部（足元・看板・屋上・小物）があるか           |
| 4. 線と陰             | 輪郭線がきれいで太さがそろい、陰の段がはっきりしているか。点滅・二重線がないか |
| 5. 色                 | 色の表の中でまとまり、差し色が効いているか。くすみ・濁りがないか               |
| 6. つむ               | 街の中で目に入り、絵柄が馴染み、動きが自然か（足の接地・振り向き・座り）       |
| 7. ページの意味       | 街の形からページの中身が分かるか（プレーヤー・カード・コメントがどこか）       |
| 8. 錯視               | 見る人の操作で「えっ」となる瞬間があるか                                       |
| 9. 操作と文字         | 近い視点で本物の操作が効き、文字が読めるか（G1）                               |
| 10. 心地よさと重さ    | 酔わないか、カクつかないか、重さの予算に入っているか                           |

合格の目安：全項目 2 以上。1・2・6・8 のうち少なくとも2つが 3。
