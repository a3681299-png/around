# 見た目の作り方

## 色の表（出発点。見て調整してよい。変えたらここも直す）

| 役割       | 色                      | 使う所                          |
| ---------- | ----------------------- | ------------------------------- |
| 空・上     | #BDEFF5                 | 空の上側                        |
| 空・地平   | #E8FBFF                 | 地平線の近く                    |
| 太陽       | #FFFFFF（縁は #DFF7FB） | 柔らかい円                      |
| 主の青     | #5AA9DE                 | 道・湖・屋根の一部              |
| 濃い青     | #2F6FA8                 | 影の側・看板                    |
| 白         | #F6FBFF                 | 横断歩道・壁の明るい側          |
| 緑         | #2E9E8C                 | 植え込み・地面の緑              |
| 薄い緑     | #8FD6B8                 | 公園・芝                        |
| 差し色・桃 | #F28AB2                 | 信号・つむの周り・大事な所に1つ |
| 屋根・赤   | #D46A72                 | 家並みの屋根                    |
| 黄         | #F2D06B                 | 点字ブロック・小さな目印        |
| 輪郭線     | #2B3A5A                 | 線                              |

差し色は画面に1つの役割だけ（大事な所に目を向けるため）。

## 陰（トゥーン）

- three.js の `MeshToonMaterial` に、2〜3段の小さな階調の画像（`NearestFilter`）を渡すのがいちばん簡単。曲げは `wwt-world-bend` の差し込みを同じ材質に入れる
- 光は太陽1つ（向きは斜め上から、建物が長めの影を落とす向き）＋弱い全体の光。陰の側が暗くなりすぎないよう、全体の光は明るめ
- 縁の光（リムライト）は、つむと大事な建物にだけ弱く

## 輪郭線

- 裏返した一回り大きい形（BackSide）で描く。太さは画面で 1.5〜3px、手前ほど太く
- 地面の模様（横断歩道・道の線）には輪郭線を付けず、色の面で描く
- 細すぎて点滅する所（電線・手すり）は、遠いときに線を消す

## 影

- 建物の影は太陽からの影の画像を小さい範囲（注目点の周り）だけで作る。陰の段と同じく、影も1段の色で塗る（ぼかさない）
- つむと小物の足元には、丸い接地の影を常に置く

## 空と遠景

- 空は見る向きで塗る（画面の位置で塗らない。カメラが動いても雲が付いてこないように）
- 太陽はふちの柔らかい円。光の筋は付けない
- 惑星の視点では、星の縁にうっすら明るい輪をつけると、一枚の絵としてまとまる

## 小物

- ローポリ、色は色の表から。例：街灯、信号、標識（架空の文字）、植え込み、ベンチ、自転車、電柱と電線、ポスト、自販機、鳥
- 出どころは CC0（例 Kenney・Quaternius。使う前に付いているライセンスの文を確かめ、出どころを記録）か自作
- 同じ物はインスタンスで描く。動かない物は材質ごとにまとめる
