# 書き出したあとの検査

## 自動で回す（スクリプトにして、書き出しのたびに回す）

`node scripts/city-assets/check.mjs`（依存なしで GLB を読む。テストは `tests/city-assets-check.spec.ts`、unit）。Khronos の gltf-validator はリポジトリに入れていないので、代わりに GLB の構造（チャンク・アクセサーの範囲）を読み、three.js の GLTFLoader で並べるページに読み込めることを確かめる。

- glTF の構造にエラーがない
- 三角形の数が上限以内
- 材質の名前が約束の表の中にある（`slot_` で始まる）
- 大きさ 1・回転 0、原点が約束どおり（足元なら、形の一番下が y=0 の近く）
- 高さが一覧の `heightM` と合う
- 人型：骨の名前が対応表にそろっている、付ける所の空の点がある
- 一覧の全部の行のファイルがあり、一覧にないファイルがない
- 出どころ（`source`）が全部の行に書いてある

検査の結果は一覧と一緒に要約を残す。落ちた物は draft にしない。
