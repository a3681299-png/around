# WWT Asset Contract

世界は素材の中身を知らなくても動く。約束どおりの GLB と一覧の1行があれば、差し替えだけで世界に入る。

## References

| File                           | Read it when                                     |
| ------------------------------ | ------------------------------------------------ |
| `references/manifest.md`       | 素材の一覧の形、置き場所、状態、出どころの書き方 |
| `references/checks.md`         | 書き出したあとの検査（自動で回す物と目で見る物） |
| `references/humanoid-bones.md` | 人型の骨の対応表（つむ・住人）と付ける所         |

## 約束

- **単位**：メートル。実寸（住人の身長はおよそ 0.9〜1.3m のデフォルメ体型。つむに合わせる）
- **向き**：glTF の決まりどおり、上は +Y、前は +Z。Blender の書き出しの設定（+Y Up）で変換する
- **原点**：住人・街の物・建物は足元の中心。手に持つ小物は握る所。船は水面の高さの中心
- **変形は適用済み**：書き出す前に大きさと回転を適用する（大きさ 1、回転 0）
- **材質の部位の名前**（色は世界が色の表から当てる。テクスチャは要る物だけ）

| 名前                                                            | 使う所                                                     |
| --------------------------------------------------------------- | ---------------------------------------------------------- |
| `slot_skin`                                                     | 肌                                                         |
| `slot_hair`                                                     | 髪                                                         |
| `slot_top`                                                      | 上着                                                       |
| `slot_bottom`                                                   | 下                                                         |
| `slot_shoes`                                                    | 靴                                                         |
| `slot_accent`                                                   | 帽子・マフラー・エプロンなどの差し色                       |
| `slot_wood` `slot_metal` `slot_stone` `slot_cloth` `slot_glass` | 物の素材                                                   |
| `slot_light`                                                    | 光る所（ランタンの火、窓、街灯の灯り）。世界が夜に光らせる |
| `slot_tex`                                                      | テクスチャを使う所（つむなど）                             |

- **人型の骨**：つむと住人は同じ人型の骨の名前の対応表を使う（hips・spine・chest・neck・head、左右の upperArm・lowerArm・hand・upperLeg・lowerLeg・foot など。WWT の今の人型の対応に合わせる）。対応表は素材の一覧と一緒に置く（`references/humanoid-bones.md`、機械が読む物は `src/playground/city-assets/humanoid.json`）。鍵は VRM の人型の名前（`scripts/characters/rigs/*.json` と同じ形）で、値は GLB の中の骨の名前。骨の名前は付け替えない（素体は `UpperArm.L`、つむは `Upper_arm.L`）。世界は対応表を通して骨を探す
- **付ける所**：人型には空の点 `attach_head`・`attach_hand_l`・`attach_hand_r`・`attach_back` を、それぞれの骨の子として置く。世界は小物をここに付ける
- **三角形の上限**（目安）：住人 1人 3,000、つむ 4,000、手の小物 500、街の物 800、船 3,000、文化の建物 6,000
- **書き出し**：GLB（バイナリ）。圧縮は世界の側の読み込みと相談して決める（Draco や meshopt を使うなら、世界が読めることを確かめてから）。アニメーションは入れない（動作は世界が CC0 の動作セットを当てる。住人は `scripts/characters/retarget_vrma.py --target-map <humanoid の住人の表> --glb-out` で Quaternius UAL の動作を焼き込める）。例外はつむ：今の世界は、動作を焼き込んだ `tsumu-city.glb` をそのまま使う。表情のシェイプキーは要る物だけ残す
- **輪郭線のため**：面の向き（法線）を外向きにそろえる。閉じていない薄い面は避ける（裏返した輪郭線がきれいに出ないため）

## 変えるとき

世界がすでに使っている約束（骨の名前・原点・材質の名前）を変えるときは、止めて聞く。足すだけ（新しい材質の名前、新しい付ける所）なら、一覧と表に書き足して報告に書く。

## Report

書き出した物、検査の結果、一覧の変更、約束に足した物。
