# 平らな動画サイト「はこにわ」（2026-11-08 決定：見本 C）

街の設計図になる、架空の動画サイト。場面1（素の Playground）そのもので、真上から見た街もこの見た目になる。名前「はこにわ」は仮。

見本のマークアップは `flat-site-hakoniwa.dc.html`（設計担当が作った見本。デザイン用の部品の書き方 `<x-dc>`・`{{ }}`・`<sc-for>` を含むので、そのままは使わず、見た目・寸法・並び・文字を写して Playground の流儀で作る）。

## いちばん大事な文法

**紺の輪郭線と、ずらした平たい影。** 平らなサイトの時点で、街のトゥーン（輪郭線・段の陰・パステル）と同じ文法で描く。適用すると、この線と影がそのまま建物の輪郭と影になる。

- 輪郭線：`2.5px solid #2B3A5A`（細い所は 2px）。真っ黒にしない
- 影：ぼかさない。右下へずらした紺の面（`box-shadow: 3〜5px 3〜5px 0 #2B3A5A`）。押すと影が縮む（押し込む感じ）
- 角の丸み：大きいカード 22px、説明 18px、一覧のカード 16px、サムネイル 10px、ボタン・検索・チップ 99px（丸）
- 余白：カードとカードの間は 16〜32px にそろえる。この隙間が街の道になる

## 文字

- Zen Maru Gothic（500・700・900）。見出しとボタンは 900、本文は 500
- 題名 30px、見出し 20px、本文 15px（行間 1.7〜1.8）、補足 12〜13px
- 文字は 4.5:1 以上

## 並び（1440px 幅で）

- ヘッダー：ロゴ（家の形の印＋「はこにわ」＋黄色の「TV」の札）、検索（丸い枠、緑のボタン）、右端に「WWT を適用」（ピンク、ずらした影）。その下にカテゴリのチップ（ぜんぶ・雨・夜・電車・屋上・音だけ）
- 左（広い）：プレーヤーのカード → 題名・チャンネル・すき／おきにいり → 説明のカード → コメント（丸いアバター＋吹き出しのカード）
- 右（狭い）：「つぎに見る」の一覧（サムネイル＋題名＋チャンネル＋回数）
- 下：フッター（「架空の動画サイトです（WWT Playground）」と「作品について」）
- スマホ幅では右の列が下に回る

## 部品

- プレーヤーの操作：丸い一時停止（紺の塗り）、時間、シーク（太めの線＋ピンクの進み＋白い丸のつまみ、つまみにずらした影）、音量（青の進み）、全画面。どれも本物の `<button>` と `<input type="range">` で、素の見た目は消して色の表で描く
- サムネイル：自前の動画の1コマ。今は見本として、空・太陽・建物3つ・地面を図形で描いている。本物の動画ができたら差し替える。輪郭線を付ける
- 中身はすべて架空（動画の題名・チャンネル・コメント）。実在のサービスやブランドに似せない

## 街になったとき（`mapping.md`）

- カードの白い面 → 建物の屋根。輪郭線 → 建物の輪郭。ずらした影 → 建物の影
- カードの間の地の色 → 道
- プレーヤー → 広場の巨大スクリーンと湖
- コメントの吹き出し → 道沿いの家や区間
